# Plan de Implementación "Visionary Canvas": La Experiencia Definitiva

He ajustado el plan para cumplir estrictamente con tu visión detallada (Estructura A-G, Identidad, WYSIWYG real y Publicación Optimizada).

## 1. Backend: Reingeniería del Arquetipo "Transformer" (Coaching)

Adaptaremos el modelo de datos y la IA para que piensen como un experto en lanzamientos High-Ticket.

*   **Nuevo Esquema de Datos (`TransformerContent`):**
    Actualizaré el modelo Pydantic para soportar la anatomía exacta que describiste:
    *   **A. Hook:** Promesa de Identidad + Tiempo.
    *   **B. PAS:** Campos separados para Problema, Agitación y Solución.
    *   **C. Mecanismo Único:** Nombre del método y explicación.
    *   **D. Autoridad:** Bio y foto de autoridad (Ileana/Camila style).
    *   **E. Stacking:** Módulos semana a semana + Bonus mata-objeciones.
    *   **F. Anclaje:** Precio Regular (Tachado) vs Oferta.
    *   **G. Escasez:** Fecha de inicio / Cupos.

*   **Prompt Engineering Avanzado (`landing_coaching_grupal.j2`):**
    *   Reescribiré el template para que la IA actúe como copywriter experto en "Venta Consultiva Automatizada".
    *   **Inyección de Activos:** La IA recibirá la lista de imágenes con sus metadatos (colores, descripciones) para asignar la foto perfecta a cada sección (ej: Foto "Lifestyle" para la sección de Identidad).

## 2. Frontend: El Editor "Visionary Canvas" (WYSIWYG)

Crearé una experiencia de edición directa sobre el diseño final.

*   **Componente `TransformerVisualEditor`:**
    Implementará visualmente las 7 secciones (A-G) con diseño profesional "Mobile First".
    *   **Edición de Textos:** Haz clic en cualquier título, párrafo o precio para editarlo en el lugar.
    *   **Edición de Imágenes:** Haz clic en una imagen para abrir la galería de medios y cambiarla.
    *   **Gestión de Módulos/Bonus:** Botones visuales para agregar/quitar elementos del Stack.

*   **Panel de Control Global:**
    *   Selector de Colores de Marca (se aplican en tiempo real).
    *   Configuración de SEO y Slug.

## 3. Publicación Optimizada (ISR)

Para cumplir la promesa de "no consultar la BD constantemente":

*   **Ruta `/p/[slug]`:**
    *   Implementaré **Incremental Static Regeneration (ISR)** de Next.js.
    *   Al "Publicar", Next.js generará una versión estática (HTML/JSON) de la landing.
    *   Las visitas subsiguientes servirán el HTML cacheado instantáneamente (como si fuera un archivo copiado), sin tocar la base de datos ni el backend.
