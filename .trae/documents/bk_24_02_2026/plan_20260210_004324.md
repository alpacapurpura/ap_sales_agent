# Plan de Implementación: "Live Brand Book"

Este plan detalla la transformación del módulo "Sobre la Marca" a una experiencia editorial interactiva, asegurando la preservación de todos los datos existentes.

## 1. Arquitectura de Página (`brand-settings/page.tsx`)
Reemplazaré el sistema de Tabs con un Layout de Dos Columnas:

*   **Izquierda: Panel de Navegación "Índice del Brand Book"**
    *   Lista de capítulos (Identidad, Voz, Equipo, Contacto) que hacen scroll suave a la sección correspondiente en la vista previa.
    *   Barra de Progreso "Brand Health" (cálculo de campos completados).
*   **Derecha: El "Live Preview" (Lienzo Interactivo)**
    *   Un contenedor visualmente rico que simula una página web corporativa moderna.
    *   Cada sección del preview tendrá un botón "Editar" flotante que abre el formulario correspondiente.

## 2. Componentes de Vista Previa (Nuevos)
Crearé componentes visuales que renderizan la data existente:

*   **`BrandHeroSection`**:
    *   Muestra: `logo_url`, `brand_name`, `industry`, `website`.
    *   Estilo: Header de Landing Page grande y moderna.
    *   Trigger: Abre `BrandIdentityForm`.
*   **`BrandVoiceSection`**:
    *   Muestra: `language`, `timezone` y un resumen visual de la personalidad (Tono, Arquetipo) extraído de `PersonalityCloneForm`.
    *   Trigger: Abre `PersonalityCloneForm`.
*   **`BrandTrustSection`**:
    *   Muestra: `legal_name`, `address` y `authority_vault` (certificaciones, premios).
    *   Trigger: Abre `BrandIdentityForm` (legal) y `AuthorityVaultForm`.
*   **`TeamGridSection`**:
    *   Muestra: `KeyFigures` (CEO, Fundadores) en formato de tarjetas de equipo.
    *   Trigger: Abre `KeyFiguresForm`.
*   **`ContactFooterSection`**:
    *   Muestra: `support_email`, `phone`, `social_*`, `testimonials_url`.
    *   Estilo: Footer de sitio web.
    *   Trigger: Abre `ContactDataForm`.

## 3. Estrategia de Edición (Sheets)
No reescribiré los formularios. Los envolveré en un componente `Sheet` de Shadcn para que aparezcan lateralmente sin salir del contexto visual.
*   Crearé un wrapper `EditSheet` que recibe `title`, `description` y el `children` (el formulario existente).
*   Al guardar el formulario, el Sheet se cierra y el Preview se actualiza automáticamente (gracias a React state).

## 4. Preservación de Datos
He verificado todos los campos en los archivos actuales y garantizo su inclusión:
*   **Identity**: `brand_name`, `legal_name`, `website`, `industry`, `logo_url`, `timezone`, `language`.
*   **Contact**: `support_email`, `phone`, `address`, `social_*` (IG, LinkedIn, YT), `testimonials_url`.
*   **Team/Authority/Avatar**: Se mantendrán sus estructuras de arrays completas.

## Ejecución
1.  Crear `components/brand-book-preview.tsx` (El orquestador visual).
2.  Crear los sub-componentes visuales (`BrandHeroSection`, etc.).
3.  Modificar `page.tsx` para implementar el layout dividido.
4.  Conectar los botones de edición a los Sheets que contienen los formularios actuales.
