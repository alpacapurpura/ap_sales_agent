# Implementación de "Logo Kit" en Brand Studio

## Estrategia General
Diseñaremos una experiencia de "Logo Kit" dentro de la sección **Universo Visual** (Identity). En lugar de un solo campo para el logo, implementaremos una matriz inteligente que permite gestionar las variantes críticas de la marca, asegurando que se visualicen correctamente en cualquier contexto (fondo claro, oscuro, responsive).

## 1. Actualización de Modelos de Datos (Backend & API)
Evolucionaremos el esquema de datos para soportar una estructura de logos tipada, manteniendo retrocompatibilidad.

- **Backend (`brand_schema.py`)**:
  - Crear clase `BrandLogos` con campos:
    - `primary`: Logo Principal (Completo).
    - `secondary`: Icono / Responsive (Favicon).
    - `dark_mode`: Versión para fondos oscuros (generalmente blanco).
    - `light_mode`: Versión para fondos claros (generalmente oscuro).
  - Actualizar `BrandIdentity` para incluir `logos: BrandLogos`.
- **Frontend (`brand.ts`)**:
  - Replicar estas interfaces en TypeScript.

## 2. Nuevos Componentes de Interfaz
Crearemos componentes reutilizables para gestionar la subida y selección de logos.

- **`single-image-picker.tsx`**:
  - Un componente optimizado para seleccionar *una sola imagen* (a diferencia del selector múltiple actual de la galería).
  - Permitirá subir archivos directamente o elegir de la galería existente.
- **`logo-kit.tsx`**:
  - Una matriz visual 2x2 (Bento Grid).
  - **Slot Principal**: Previsualización grande sobre fondo transparente (checkerboard).
  - **Slot Secundario**: Previsualización cuadrada pequeña.
  - **Slot Dark Mode**: Previsualización sobre fondo **Negro** forzado (para validar contraste).
  - **Slot Light Mode**: Previsualización sobre fondo **Blanco** forzado.

## 3. Integración en Brand Studio
- **Formulario (`identity-form.tsx`)**:
  - Reemplazar el input de texto `logo_url` actual con el nuevo componente `LogoKit`.
  - Conectar los eventos de cambio para actualizar el estado del formulario.
- **Previsualización (`identity-section.tsx`)**:
  - Mostrar la matriz de logos en la vista de "Solo Lectura" para que el usuario confirme cómo se ven sus activos.

## Experiencia de Usuario (UX)
Esta solución guía al usuario implícitamente:
- Al ver un recuadro negro etiquetado "Fondo Oscuro", el usuario entenderá que debe subir un logo blanco/claro sin necesidad de leer instrucciones complejas.
- El sistema de "Slots" ordena el caos habitual de archivos sueltos (PNGs, SVGs) en una estructura profesional.
