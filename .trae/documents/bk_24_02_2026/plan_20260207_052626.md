# Proposal: Offer "Flight Check" System

We will implement a real-time "Flight Check" module in the right-hand panel (`OfferContextPanel`) that acts as a co-pilot, showing exactly what is missing to make the offer "Launch Ready".

## 1. The "Flight Check" Component

Instead of just static help text, we will add a dynamic **Validation Card** at the top of the right panel.

### Visual Design (Shadcn/UI)

* **Status Indicator**: A progress ring or simple "X/Y Completed" badge.

* **Alert State**: If critical fields are missing, use an `Alert` (amber/red).

* **Success State**: If all mandatory fields are filled, show a "Ready to Launch" (green) card.

### Validation Logic (Business Rules)

We will define strict "Readiness Rules" beyond the basic database schema:

**Phase 1: Identity (The Context)**

* [ ] `public_name`: Required.

* [ ] `type`: Required.

* [ ] `avatar_id`: Required (You can't sell to no one).

**Phase 2: Value (The Solution)**

* [ ] `headline_promise`: Required.

* [ ] `primary_outcome`: Required.

* [ ] `time_to_value`: Required.

* [ ] `deliverables`: At least 1 item (Empty offers don't sell).

**Phase 3: Economics (The Deal)**

* [ ] `pricing_options`: At least 1 price (Even free offers need a $0 price).

* [ ] `onboarding_action`: Required (How do they actually get it?).

## 2. Implementation Steps

1. **Create Validation Utility**: `getOfferValidationStatus(values)` function to return a list of missing fields and a completion percentage.
2. **Update** **`OfferContextPanel.tsx`**:

   * Insert the `<FlightCheckCard />` at the top of the sticky sidebar.

   * Make the items clickable (if possible) to switch phases, or at least clearly labeled with the Phase number.
3. **UI Polish**:

   * Use `lucide-react` icons (`AlertTriangle`, `CheckCircle`, `XCircle`).

   * Use `Badge` for quick visual scanning.

## 3. Expected Outcome

The user will see a list like:

```text
⚠️ Faltan 3 campos obligatorios:
- [Fase 1] Avatar Match
- [Fase 2] Gran Promesa
- [Fase 3] Al menos un Precio
```

As they type, these items will disappear in real-time.
