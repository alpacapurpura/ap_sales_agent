# Solución de Flight Check (Acordeón y Scroll)

El problema de "faltan 4 requisitos pero solo se muestran 2" se debe a que el componente `FlightCheckCard` tiene una altura máxima muy restrictiva (`max-h-[120px]`) en su área de scroll, y visualmente no está claro que se puede hacer scroll, o el scroll está oculto por estilos CSS (`scrollbar-width: none`).

Además, para ganar espacio vertical como solicitaste, implementaré un **Acordeón Colapsable**.

## Solución Técnica

### 1. Transformación a Acordeón (`Collapsible`)
Modificaré `FlightCheckCard` en `offer-context-panel.tsx` para usar el componente `Collapsible` de Radix/Shadcn (o estado local si no queremos añadir dependencias).
*   **Estado por defecto**: `isOpen = false` (Colapsado).
*   **Vista Colapsada**: Muestra solo el Header (Badge "Flight Check", Barra de Progreso y Resumen "Faltan X requisitos").
*   **Vista Expandida**: Despliega la lista completa de requisitos faltantes.

### 2. Corrección de Scroll y Altura
*   Eliminaré la restricción `max-h-[120px]` cuando esté expandido, o la aumentaré significativamente (`max-h-[300px]`) para que se vean más items cómodamente.
*   Al ser un acordeón que empuja el contenido hacia abajo, y dado que ya arreglamos el scroll del contenedor padre (`OfferContextPanel`), esto funcionará perfectamente sin cortar contenido.

### 3. Implementación
Modificaré `frontend/src/features/offer-studio/components/ui/offer-context-panel.tsx`:
*   Importar `ChevronDown` / `ChevronUp`.
*   Añadir estado `const [isExpanded, setIsExpanded] = useState(false)`.
*   Envolver el `CardContent` en un condicional o clase de animación.
*   Hacer clickeable el `CardHeader` para alternar el estado.

Esto liberará mucho espacio vertical para el contenido de ayuda ("Construcción de Oferta") y resolverá el problema de visibilidad de los requisitos faltantes.
