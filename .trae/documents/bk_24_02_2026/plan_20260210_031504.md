# Smart Contrast & Chameleon Theme Implementation

## 1. Color Utilities (`src/lib/utils/colors.ts`)
Create a robust color manipulation library to handle the user's "intelligence" requirement:
- `getContrastColor(hex)`: Returns 'black' or 'white' based on luminance (WCAG logic).
- `adjustBrightness(hex, percent)`: Lightens/Darkens a color (for creating harmonious card backgrounds).
- `hexToHsl(hex)`: Moves the existing logic here for reuse.

## 2. Upgrade `ThemeInjector` (Global Fix)
Refactor `src/features/brand/components/visuals/theme-injector.tsx` to apply "Smart Theming" instead of blind injection:
- **Smart Foreground:** If the extracted `text_primary_color` has poor contrast against `background_color`, override it with `getContrastColor(background_color)`.
- **Harmonious Cards:** Instead of setting `--card` = `--background` (which looks flat), set `--card` to be 10% lighter (if dark theme) or 5% darker (if light theme) than the background. This solves the "huachafo" (tacky/clashing) look.
- **Readable Primary:** Ensure `--primary-foreground` is always high-contrast against `--primary`.

## 3. Refactor Contact Footer
Update `src/features/brand/components/live-preview/contact-footer-section.tsx`:
- Add `visuals` prop.
- Explicitly set `backgroundColor: visuals.primary_color` and `color: getContrastColor(visuals.primary_color)` to guarantee readability regardless of the extracted color.

## 4. Refactor Team Grid & Trust Sections (Optional but recommended)
- Add `visuals` prop to `TeamGridSection` and `BrandTrustSection`.
- Apply explicit background/text styles if the global CSS variables aren't catching (double-safety).
- **Focus:** I will rely on `ThemeInjector` for these first, as it's cleaner, but adding the prop prepares them for inline overrides if needed.

## 5. Wiring it up
- Update `src/features/brand/components/brand-book-preview.tsx` to pass the `visuals` prop to the Footer (and other sections if modified).

This approach ensures that **any** color extracted (dark or light) results in a readable, professional UI without the user having to manually fix it.
