# Plan de Implementación: Puck "Visionary Architect" (Backend-Driven)

Este plan alinea la arquitectura existente de "Arquetipos" del backend con la flexibilidad visual de Puck, permitiendo que la estructura se defina automáticamente según el tipo de oferta, mientras se habilita la edición visual y la regeneración con IA.

## 1. Gestión de "Paquetes" (Estructuras Predefinidas)
Ya dispones de la lógica en `backend/src/core/domain/landing_page/archetype_map.py`. No necesitamos crear un nuevo "Wizard", sino potenciar este mapeo existente.

*   **Tu Control (Expert Mode)**: Para modificar qué secciones aparecen en cada tipo de oferta, editarás directamente `archetype_map.py` y las plantillas `.j2`.
*   **Acción**: Revisar `adapter.ts` en el frontend para asegurar que no esté "harcodeando" siempre los mismos 6 bloques, sino que respete dinámicamente la lista de secciones que envía el backend. Si el backend envía 3 "ModuleSection", Puck debe renderizar 3, no 1.

## 2. Nivel 1: Variantes Visuales (El mismo bloque, diferente look)
Para permitir cambios estéticos sin romper la estructura, añadiremos selectores de estilo en la configuración de Puck.

*   **Archivo**: `frontend/src/features/landing-builder/puck.config.tsx`
*   **Implementación**:
    *   Añadir campo `layout` o `variant` a los bloques clave (Hero, Offer, Stack).
    *   *Ejemplo Hero*: Opciones `["Split (Classic)", "Centered (Video)", "Background (Immersive)"]`.
    *   **Render**: El componente React leerá `props.layout` y cambiará clases CSS (Tailwind) o la disposición de elementos (flex-row vs flex-col) instantáneamente.

## 3. Integración de IA Generativa (Puck + Contexto)
Para cumplir el requisito de "pedirle a la IA que rehaga esa sección", implementaremos una acción contextual en el editor.

*   **Backend**: Crear endpoint `POST /api/v1/landing/ai/regenerate-block`.
    *   *Input*: `offerId`, `blockType` (ej. Hero), `currentContent`, `userInstruction` (opcional).
    *   *Logic*: Usa `OfferGeneratorService` con el contexto de la marca para reescribir copy o sugerir otra variante visual.
*   **Frontend**:
    *   Añadir un botón "✨ AI Remix" en la barra de herramientas de Puck (usando `overrides.header` o un campo custom en los bloques).
    *   Al hacer clic, envía el bloque seleccionado a la API y actualiza sus props con la respuesta.

## 4. Hoja de Ruta Inmediata
1.  **Refactorizar Adapter**: Asegurar que `adapter.ts` mapee 1:1 lo que viene del backend (soporte para N secciones del mismo tipo).
2.  **Variantes Visuales**: Implementar la propiedad `layout` en el `HeroSection` como piloto.
3.  **Conexión IA**: Implementar el botón de regeneración básica (reescritura de textos) para el Hero.
