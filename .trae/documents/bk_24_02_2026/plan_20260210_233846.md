# Plan de Implementación: Botón "Ayuda IA" para Psicología de Ventas

## 1. Backend: Prompt Engineering
Crear un template de prompt robusto que instruya al LLM para actuar como un experto en copywriting y psicología de ventas.
- **Archivo:** `backend/src/core/prompts/templates/offer_psychology_generator.j2`
- **Contenido:** Instrucciones para analizar el Avatar (dolores, deseos actuales) y generar 5 Puntos de Dolor y 5 Deseos refinados y persuasivos.

## 2. Backend: Capa de Servicio y Lógica
Implementar la lógica de generación utilizando `ChatOpenAI` con salida estructurada (JSON) para garantizar la compatibilidad con el frontend.
- **Schema:** Definir `PsychologyGenerationRequest` y `PsychologyGenerationResponse` en `backend/src/core/domain/offer/schema.py` (o nuevo archivo `ai_schema.py`).
- **Servicio:** Crear `backend/src/services/offer_generator_service.py`.
    - Método `generate_psychology`:
        1. Recibir `avatar_id` y datos actuales.
        2. Obtener detalles del Avatar desde la BD.
        3. Renderizar el prompt.
        4. Invocar LLM (GPT-4o) con `with_structured_output`.
        5. Retornar Pydantic model.

## 3. Backend: API Endpoint
Exponer la funcionalidad a través de un nuevo endpoint seguro.
- **Router:** Crear `backend/src/api/routers/offer_ai.py`.
- **Endpoint:** `POST /api/v1/offers/ai/psychology`.
- **Registro:** Montar el router en `backend/src/main.py`.

## 4. Frontend: Cliente API y Componentes
Integrar la llamada al backend y crear la interfaz de usuario.
- **API Client:** Añadir método `generatePsychology` en `frontend/src/lib/api/offer.ts`.
- **Componente Reutilizable:** Crear `frontend/src/features/offer-studio/components/ai-assist-button.tsx`.
    - Botón con icono `Sparkles`.
    - Estado de carga y manejo de errores.
    - Tooltip explicativo si está deshabilitado (cuando no hay Avatar).

## 5. Frontend: Integración en Offer Editor
Conectar el botón en el flujo de trabajo del usuario.
- **Archivo:** `frontend/src/features/offer-studio/components/offer-editor.tsx`.
- **Ubicación:** Header de la tarjeta "Psicología de Ventas".
- **Lógica:**
    - Habilitar solo si `avatar_id` está seleccionado.
    - Al recibir respuesta de la IA, usar `append` (de `useFieldArray`) para agregar los nuevos dolores y deseos sugeridos al formulario.
