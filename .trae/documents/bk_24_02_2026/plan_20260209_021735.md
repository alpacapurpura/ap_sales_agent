# Optimización de Arquitectura API: Generación Automática de Clientes

Este plan implementa un flujo de trabajo profesional donde el Frontend se sincroniza automáticamente con el Backend, eliminando errores humanos y código manual, sin la complejidad de gRPC.

## 1. Preparación del Backend (FastAPI)
- **Objetivo:** Asegurar que `openapi.json` sea consumible por generadores de código.
- **Acciones:**
    - Revisar `main.py` y routers para asegurar que cada endpoint tenga un `operation_id` único y descriptivo (ej: `get_products` en lugar de `get_products_api_v1_products_get`).
    - Verificar que los modelos Pydantic tengan nombres claros en el esquema.

## 2. Integración en Frontend (Next.js)
- **Objetivo:** Generar un SDK de TypeScript totalmente tipado basado en el Backend.
- **Acciones:**
    - Instalar `openapi-typescript-codegen` como dependencia de desarrollo.
    - Crear script en `package.json`: `"gen:api": "openapi --input http://localhost:8000/openapi.json --output ./src/lib/api-client --client axios"`.
    - Configurar una instancia base de Axios (o Fetch) que inyecte automáticamente el token de autenticación (Clerk) y la URL base, para que el código generado la utilice.

## 3. Refactorización Piloto (Módulo 'Products')
- **Objetivo:** Demostrar la mejora en mantenibilidad y DX.
- **Acciones:**
    - Eliminar las interfaces manuales en `frontend/src/lib/api/offer.ts` (o similar).
    - Reemplazar las llamadas `fetch` manuales por llamadas al cliente generado:
      ```typescript
      // Antes (Manual y propenso a errores)
      const res = await fetch('/api/v1/products');
      const data: Product[] = await res.json();
      
      // Después (Autocompletado y Tipado Real)
      const data = await ProductsService.getProducts();
      ```
    - Verificar que la aplicación sigue funcionando correctamente.

## 4. Limpieza y Documentación
- **Objetivo:** Establecer el nuevo estándar.
- **Acciones:**
    - Documentar el comando `npm run gen:api` en las reglas de desarrollo.
    - (Opcional) Agregar la generación al flujo de build de Docker para asegurar que siempre esté sincronizado.
