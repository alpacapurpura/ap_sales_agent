# Plan de Implementación: Widget de Mentores en Panel Lateral (Opción C)

Este plan implementa la gestión de mentores ("Key Figures") directamente desde el Panel de Contexto (derecha), manteniendo el flujo de edición principal limpio y permitiendo una gestión ágil de la "Autoridad" de la oferta.

## 1. Backend: Persistencia de Datos

### 1.1. Actualizar Schema de Oferta (`backend/src/core/domain/offer/schema.py`)

* Añadir campo `instructors` al modelo `Offer`.

* Tipo: `List[str]` (Lista de IDs de KeyFigures).

* Default: `[]`.

### 1.2. Actualizar Schema de KeyFigure (`backend/src/core/domain/brand_schema.py`)

* Añadir campo `headshot_url` al modelo `KeyFigure`.

* Tipo: `Optional[str]`.

* Descripción: "URL de la foto de perfil del mentor".

## 2. Frontend: Interfaces y Componentes

### 2.1. Actualizar Tipos TypeScript

* **`lib/api/offer.ts`**: Añadir `instructors: string[]` a la interfaz `Offer`.

* **`lib/api/brand.ts`**: Añadir `headshot_url?: string` a la interfaz `KeyFigure`.

### 2.2. Mejorar `KeyFiguresForm`

* **Ubicación**: `features/brand/components/key-figures-form.tsx`

* **Cambio**: Agregar campo para `headshot_url`.

* **UX**: Input simple para URL de imagen (para mantener estabilidad técnica) + Previsualización de Avatar.

* **Validación**: Asegurar que se guarde correctamente en el Brand Book.

### 2.3. Nuevo Componente: `InstructorsWidget`

* **Ubicación**: `features/offer-studio/components/widgets/instructors-widget.tsx`

* **Diseño**:

  * Estilo "Card" minimalista para el Panel Lateral.

  * Muestra un "Avatar Group" de los mentores seleccionados.

  * Botón "Gestionar Autoridad" que abre un Dialog.

* **Dialog de Selección**:

  * Lista todos los `KeyFigures` del Tenant (BrandSettings).

  * Checkbox para seleccionar/deseleccionar.

  * Botón "Crear Nuevo" que abre el `KeyFiguresForm` en un nested dialog (o modo edición).

### 2.4. Integración en `OfferContextPanel`

* **Ubicación**: `features/offer-studio/components/ui/offer-context-panel.tsx`

* **Lógica**:

  * Inyectar el `InstructorsWidget` en la sección superior del panel (o bajo el resumen de estado).

  * **Condicional**: Solo mostrar si el `OfferType` es de conocimiento (Course, Coaching, Mentorship).

  * **Comunicación**:

    * Pasar una nueva prop `onUpdateInstructors` desde el `OfferEditor` padre al `OfferContextPanel`.

    * El `OfferEditor` manejará esta función ejecutando `form.setValue('instructors', ids, { shouldDirty: true })`.

## 3. Pasos de Ejecución

1. **Backend Changes**: Modificar Pydantic models.
2. **Types Update**: Sincronizar interfaces frontend.
3. **Widget Creation**: Desarrollar `InstructorsWidget` aislado.
4. **Wiring**: Conectar `OfferEditor` -> `OfferContextPanel` -> `InstructorsWidget`.
5. **Verification**: Probar flujo completo (Crear Mentor -> Asignar a Oferta -> Guardar Oferta -> Recargar).
