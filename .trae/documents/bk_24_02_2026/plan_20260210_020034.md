# Conexión del "Brand Visuals" con el Extractor Web Real

El problema es que el frontend actualmente usa datos simulados (mock) porque el extractor real no estaba conectado a la API. Los colores incorrectos (`#2563eb`, `#f59e0b`) son valores "dummy" escritos en el código del frontend.

Para solucionar esto y obtener los colores reales de `visionarias.lat` (el bordó y el crema), implementaré la conexión completa Backend-Frontend.

## 1. Backend: Exponer el Extractor como API
Crearé un nuevo Router `tools.py` que permita al frontend invocar el `web_extractor_graph` que creamos anteriormente.

### A. Mejorar la Extracción de Colores (`web_extractor/nodes.py`)
El `fetch_html` actual elimina estilos (`style.decompose()`). Para obtener colores precisos, modificaré el nodo `fetch_html` para que:
1.  **Conserve los estilos** o extraiga patrones hexadecimales (`#RRGGBB`) usando Regex antes de limpiar.
2.  Pase estos "candidatos de color" al LLM en el campo `raw_content` para que el LLM pueda decidir cuál es el primario basándose en la frecuencia o el contexto CSS.

### B. Crear Esquema `BrandIdentity` (`core/domain/schema.py`)
Definiré el modelo Pydantic que el extractor debe rellenar:
```python
class BrandIdentity(BaseModel):
    primary_color: str = Field(..., description="Main brand color (hex)")
    accent_color: str = Field(..., description="Secondary/Accent color (hex)")
    font_heading: Optional[str] = Field(None, description="Font family for headings")
    font_body: Optional[str] = Field(None, description="Font family for body text")
```

### C. Crear Endpoint (`api/routers/tools.py`)
```python
@router.post("/extract/brand-identity")
async def extract_brand_identity(url: str):
    return await extract_from_url(url, BrandIdentity)
```

### D. Registrar Router (`main.py`)
Añadir `app.include_router(tools.router, prefix="/api/v1/tools")`.

## 2. Frontend: Consumir la API Real

### A. Actualizar Cliente API (`lib/api/brand.ts`)
Añadir función `extractBrandIdentity(url: string)` que llame a `/api/v1/tools/extract/brand-identity`.

### B. Conectar Wizard (`brand-visuals-wizard.tsx`)
Reemplazar la simulación `setTimeout` con la llamada real:
```typescript
const result = await extractBrandIdentity(websiteUrl);
setSelectedVisuals({ ...result }); // Colores reales del backend
```
