# Implementación de "The Living Canvas" Landing Studio

## 1. Backend: Arquitectura de Bloques Inteligentes
- **Modelo de Datos (`LandingPage`)**:
    - `sections`: JSONB Array. Cada objeto representa un bloque UI (`type`: 'hero', 'features', 'pricing', etc.) con su `content` (textos, imágenes) y `variant` (estilo).
    - `global_settings`: JSONB para overrides de marca específicos de esta landing (ej. forzar modo oscuro).
- **Servicio IA (`LandingArchitect`)**:
    - **Endpoint de Streaming**: `/api/v1/offers/{id}/landing/stream`. Genera la estructura bloque a bloque para el efecto visual de "construcción en vivo".
    - **Regeneración Granular**: Capacidad de regenerar solo un bloque específico (ej. "Reescribe solo los beneficios").

## 2. Frontend: Interfaz "Living Canvas"
- **Ruta**: `/offer-studio/offer/[id]/landing`.
- **Layout**: Full-screen, sin sidebar de navegación habitual (botón de "Exit" flotante).
- **Componentes Core**:
    - **`CanvasRenderer`**: Itera sobre el array `sections` y renderiza el componente correspondiente.
    - **`SmartBlockWrapper`**: HOC (Higher Order Component) que añade la capa de interacción (hover borders, botones de acción flotantes) a cada sección.
    - **`ArchitectBar` (Bottom)**: Componente flotante con input de chat para comandos IA ("Cambia el tono", "Añade FAQ") y controles de publicación.
    - **`InlineTextEditor`**: Componente que reemplaza textos estáticos con `contentEditable` limpio al hacer clic.

## 3. Biblioteca de Arquetipos (Bloques Shadcn)
Implementar componentes visuales modulares para cada arquetipo:
- **Hero Sections**: Variantes 'Squeeze' (Input grande), 'Event' (Cuenta regresiva), 'Brand' (Video fondo).
- **Value Stacks**: Grids de beneficios, Listas con checks.
- **Social Proof**: Carruseles de logos, Grids de testimonios tipo "Muro de Amor".
- **CTA Blocks**: Botones de compra flotantes o estáticos.

## 4. Integración de Marca
- **Theme Injection**: El `CanvasRenderer` inyectará variables CSS CSS (`--primary`, `--font-heading`) extraídas de `BrandSettings` en el contenedor raíz, asegurando que cualquier componente Shadcn herede la identidad visual automáticamente.

## 5. Publicación
- **Deploy Instantáneo**: Al guardar, el JSON se consolida.
- **Ruta Pública SSR**: `/visit/[slug]` (o subdominio) lee el JSON y renderiza los mismos componentes (sin los wrappers de edición) para máxima velocidad y SEO.
