# Expansión de "ADN Visual" (Contexto + Guía de Estilo)

Para que la IA pueda "replicar" el diseño de una marca, no basta con 2 colores. Necesitamos un **Sistema de Diseño Básico**.

## 1. Actualización del Esquema (`backend/src/core/domain/schema.py`)

Expandiré `BrandIdentity` para capturar un sistema de diseño completo:

```python
class BrandIdentity(BaseModel):
    # --- Core Colors ---
    primary_color: str = Field(..., description="Main brand color (hex)")
    accent_color: str = Field(..., description="Secondary/Action color (hex)")
    
    # --- Extended Palette (Nuevo) ---
    background_color: str = Field("#FFFFFF", description="Main page background color (usually white or very light gray)")
    text_primary_color: str = Field("#000000", description="Main text color (usually black or very dark gray)")
    text_on_primary: str = Field("#FFFFFF", description="Text color to use on top of primary color elements (accessibility)")
    
    # --- Typography ---
    font_heading: Optional[str]
    font_body: Optional[str]
    
    # --- Context & Rules (Nuevo) ---
    design_style: str = Field(..., description="Brief style description (e.g., 'Minimalist, Clean, Corporate', 'Vibrant, Playful')")
    usage_guidelines: List[str] = Field(default_factory=list, description="Inferred rules (e.g., 'Use primary color for buttons', 'Headers are dark', 'Cards have shadows')")
```

## 2. Mejora del Extractor (`web_extractor/nodes.py`)

### A. Trazabilidad de Colores
El `BrandColorExtractor` actual calcula puntuaciones. Lo modificaré para que también rastree **dónde** se encontró el color.
*   Antes: `#000 -> Score 5.0`
*   Ahora: `#000 -> Score 5.0 | Contexts: ['.footer', '.nav-bar', 'body text']`

Esto permitirá al LLM inferir reglas como: *"El negro se usa para el footer y la navegación"*.

### B. Prompt del LLM ("Design System Analyst")
Actualizaré el prompt del sistema para que actúe como un **Diseñador UI Senior**:
*   "Analiza no solo los colores, sino cómo se usan".
*   "Deduce si el sitio es 'Dark Mode', 'Clean', 'Corporate'".
*   "Define qué color de texto es legible sobre el color primario".
