Implementaré un nuevo componente de selección múltiple ("Buscador de Ofertas") para reemplazar la entrada manual de UUIDs.

### Pasos de Implementación:

1.  **Nuevo Componente UI: `OffersMultiSelect`**
    *   Crearé `frontend/src/features/offer-studio/components/ui/offers-multi-select.tsx`.
    *   Utilizará `useQuery` para cargar dinámicamente las ofertas disponibles usando `offerApi.listOffers`.
    *   Implementará una interfaz basada en `Command` y `Popover` (estilo Shadcn UI) que permite:
        *   **Buscar** ofertas por nombre.
        *   **Ver** el nombre y una breve descripción (`headline_promise`) de cada oferta.
        *   **Seleccionar** múltiples ofertas.
        *   **Visualizar** las ofertas seleccionadas como etiquetas (badges) con opción de eliminación.

2.  **Integración en `ValueStackStep`**
    *   Modificaré `frontend/src/features/offer-studio/components/steps/value-stack-step.tsx`.
    *   Reemplazaré el campo `Input` simple por el nuevo `OffersMultiSelect`.
    *   Conectaré el componente al formulario (`react-hook-form`) para guardar los UUIDs seleccionados en el campo `includes_offers`.

Esta solución elimina la necesidad de conocer los UUIDs de memoria y proporciona contexto visual (nombre/descripción) al seleccionar ofertas para bundling.
