# Ejecución: Brand Studio UI Refinement

Para asegurar la elegancia visual sin saturar ("Christmas Tree Effect"), aplicaré una estrategia de **Gamificación Sutil**:

## 1. El Riel Izquierdo (BrandNavRail)
*   **Estética:** `Glassmorphism` (fondo translúcido) para flotar sobre el contenido sin bloquear.
*   **Indicadores:** En lugar de cambiar el color de todo el icono (que se ve tosco), usaré:
    *   **Punto de Estado:** Un pequeño "dot" (6px) en la esquina del icono. (🟢 Verde Muted / 🟡 Ambar Suave / ⚪ Gris Opaco).
    *   **Indicador Activo:** Una línea vertical sutil (`border-l-2`) para indicar "Estás aquí".
*   **Animación:** Transiciones suaves (`duration-300`) al expandir.

## 2. El Sidebar Derecho (Listas)
*   **Limpieza:** No usaré bordes de colores agresivos.
*   **Badges:** Agregaré `Badges` minimalistas dentro de las tarjetas (ej. "Incompleto" en texto pequeño y color suave).
*   **Iconografía:** Usar un icono de `CheckCircle2` (Lucide) sutil a la derecha del nombre del item para confirmar completitud.

## 3. Arquitectura Técnica
*   **Nuevo Componente:** `src/features/brand/components/navigation/brand-nav-rail.tsx` (Separación de responsabilidades).
*   **Lógica de Negocio:** `src/features/brand/utils/brand-validation.ts` (Centralizar reglas de "qué es completo").
*   **Integración:** Actualizar `brand-settings/page.tsx` para reemplazar el `aside` antiguo.

Procederé a implementar estos componentes manteniendo la armonía visual actual.
