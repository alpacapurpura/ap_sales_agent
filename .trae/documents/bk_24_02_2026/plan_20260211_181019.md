I will implement an enhanced image selection experience for Team Members, allowing selection from the Brand Gallery and association of multiple images.

### Backend Changes
**File:** `backend/src/core/domain/brand_schema.py`
- Update `KeyFigure` schema to include `gallery: List[str]` (list of image URLs).
- Keep `headshot_url` as the currently active/primary profile photo.

### Frontend Changes
**1. Type Definitions**
**File:** `frontend/src/lib/api/brand.ts`
- Update `KeyFigure` interface to include `gallery?: string[]`.

**2. New Component: `ImageGalleryPicker`**
**File:** `frontend/src/features/brand/components/shared/image-gallery-picker.tsx`
- **Functionality:**
    - Displays selected images (thumbnails).
    - Allows adding images via a Dialog (Modal).
    - **Dialog:**
        - Fetches images using `galleryApi.list`.
        - Displays a grid of Brand Gallery images.
        - Includes an "Upload" tab to add new images to the gallery on the fly.
        - Supports multi-selection (up to 5).
    - **Selection Logic:**
        - User picks images -> they are added to the team member's `gallery`.
        - User clicks a thumbnail in the form -> sets it as `headshot_url` (Primary).

**File:** `frontend/src/features/brand/components/forms/team-member-form.tsx`
- Remove the simple URL text input.
- Integrate `ImageGalleryPicker`.
- Handle logic to switch between the "active" headshot from the personal gallery.
- Ensure image URLs are correctly formatted (handling relative paths from backend vs absolute URLs).

### UX/UI Design
- **Sidebar Integration:** The picker fits naturally in the form.
- **Visuals:** Thumbnails with a "Star" indicator for the primary photo.
