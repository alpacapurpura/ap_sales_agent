# Solución Definitiva para Extracción de Color "Inteligente"

Para resolver el problema de `visionarias.lat` (y de cualquier sitio moderno) de forma robusta, implementaré una solución en dos frentes que combina **ingeniería inversa de CSS** y **análisis heurístico semántico**, superando la simple frecuencia de píxeles.

## 1. El Problema Detectado

El método anterior fallaba porque:

1. **Ceguera a CSS Externo**: `visionarias.lat` (Shopify) tiene sus colores definidos en archivos `.css` externos, no en el HTML.
2. **Frecuencia vs. Importancia**: El color "más frecuente" suele ser blanco, negro o gris de fondo, no el color de marca.
3. **Falta de Contexto**: `#28a745` (verde éxito) y `#006FCF` (azul link) son colores funcionales de librerías, no identidad de marca.

## 2. Nueva Arquitectura del Extractor (`web_extractor/nodes.py`)

Implementaré la clase `BrandColorExtractor` (basada en mi investigación) dentro de `nodes.py` con estas capacidades:

### A. Fetcher Mejorado ("Crawler Ligero")

El nodo `fetch_html` evolucionará:

1. **Descarga CSS**: Buscará etiquetas `<link rel="stylesheet">` y descargará los 3 archivos CSS principales en paralelo (ignorando CDNs comunes como bootstrap o font-awesome si es posible).
2. **Parsing Semántico**: En lugar de extraer todos los hex codes, buscará pares `propiedad: valor`.

   * `background-color: #HEX` -> **Peso Alto (3x)**

   * `color: #HEX` -> Peso Bajo (1x)

   * `border-color: #HEX` -> Peso Medio (0.5x)

### B. Algoritmo de Puntuación (Scoring System)

Implementaré un sistema de puntos para rankear los candidatos de color:

1. **Context Boost**: Si el color aparece dentro de selectores con nombres clave (`.btn-primary`, `.header`, `.cta`, `nav`), su puntuación se multiplica por **2x**.
2. **Neutral Penalty**: Convertiré cada color a espacio **HSL**.

   * Si `Saturación < 10%` (Grises) -> Penalización masiva (-95%).

   * Si `Luminosidad > 95%` (Blancos) o `< 10%` (Negros) -> Penalización masiva.

   * Esto asegura que el color "bordó" de Visionarias gane, incluso si hay menos píxeles de ese color que de fondo blanco.

### C. Inferencia LLM con Datos Ricos

En lugar de pasar una lista ciega de colores, pasaré al LLM un resumen estructurado:

```text
[SYSTEM DETECTED CANDIDATES]
1. #7D2E40 (Score: 85.4) - Found in: .header-bg, .btn-primary
2. #EAD8C0 (Score: 60.2) - Found in: .accent-box
3. #FFFFFF (Score: 12.0) - Filtered (Neutral)
```

Esto le da al LLM la "confianza" matemática para elegir el `#7D2E40` (Bordó) como primario.

## 3. Pasos de Implementación

1. **Instalar Dependencias**: `cssutils` (opcional, o regex robusto) y `aiohttp` para descargas paralelas de CSS.
2. **Refactorizar** **`nodes.py`**:

   * Implementar `fetch_css_files()`.

   * Implementar `BrandColorExtractor` con lógica HSL y Scoring.

   * Actualizar el prompt del sistema para interpretar el nuevo formato de candidatos.

Esta solución es **agnóstica** (funciona para cualquier web) y **resiliente** (filtra ruido automáticamente).
