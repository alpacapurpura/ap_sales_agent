# Plan Final de Implementación: Módulo de Recursos + UX Contextual

Implementaremos la solución "Opción 2" (Módulo Unificado) con una mejora significativa en la experiencia de usuario en el panel derecho (Context Panel), para dar feedback visual inmediato sobre cómo estos recursos "potencian" al agente.

## 1. Esquema de Datos (`schema.ts`)
Actualizaremos `OfferSchema` con dos nuevos arrays tipados:
*   `sales_assets`: Array de objetos `{ id, type (VIDEO/IMG/AUDIO), url, trigger_context }`.
*   `knowledge_docs`: Array de objetos `{ id, name, url, size }` (Flag `is_knowledge_base: true`).

## 2. Panel Izquierdo: `ResourcesStep` (Input)
Ubicado al final de la **Fase 2 (Solución)**.
*   **Diseño**: Tarjeta con Pestañas "Material de Venta" vs "Cerebro Técnico".
*   **Funcionalidad**:
    *   Reutilización y mejora de `AssetUploader` para soportar metadatos (triggers).
    *   Validación de tipos de archivo.

## 3. Panel Derecho: UX "Antes, Durante, Después"
Modificaremos `SolutionPhaseContent` en `offer-context-panel.tsx` para incluir una tarjeta reactiva **"Nivel de Equipamiento del Agente"**:

*   **Estado 0: Agente "Desnudo" (Antes)**
    *   **Visual**: Icono de agente en gris/transparente.
    *   **Mensaje**: *"Tu agente puede prometer, pero no demostrar. Sin manuales, no puede responder dudas técnicas profundas."*
    *   **Color**: Gris/Amber neutro.

*   **Estado 1: Cargando Recursos (Durante)**
    *   **Visual**: Barra de progreso "Persuasión" y "Conocimiento".
    *   **Feedback Inmediato**: Al subir un video, aparece *"¡Genial! Ahora el agente puede mostrar evidencia visual cuando el usuario dude."*
    *   **Feedback Técnico**: Al subir un PDF, aparece *"Cerebro expandido: El agente ahora puede leer tu manual técnico."*

*   **Estado 2: Agente Equipado (Después)**
    *   **Visual**: Icono de agente "brillando" o con herramientas (badge de check).
    *   **Resumen**: *"Agente listo para debatir objeciones con evidencia y soporte técnico."*
    *   **Lista**: Muestra miniaturas de los assets cargados como "Armas disponibles".

## 4. Ejecución Técnica
1.  **Schema**: Definir tipos Zod.
2.  **Componentes**: Crear `ResourcesStep.tsx` y actualizar `OfferContextPanel.tsx`.
3.  **Integración**: Conectar en `OfferEditor.tsx`.

Esta implementación conecta la acción de "subir un archivo" con el beneficio directo de "hacer al agente más inteligente/persuasivo", incentivando al usuario a completar la sección.
