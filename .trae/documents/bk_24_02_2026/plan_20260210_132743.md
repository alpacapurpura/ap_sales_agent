# Plan de Implementación: Galería de Marca con Análisis IA

Este plan implementa una nueva sección "Galería" en el Brand Book que permite subir imágenes, almacenarlas públicamente y enriquecerlas automáticamente con metadatos generados por IA (descripción y paleta de colores) para su uso futuro en landing pages.

## 1. Infraestructura y Backend

### A. Almacenamiento Estático
*   **Directorio Público**: Crear carpeta `backend/static/gallery` para almacenamiento persistente de imágenes.
*   **Servidor de Archivos**: Configurar `StaticFiles` en FastAPI (`main.py`) montado en `/static` para servir las imágenes públicamente (e.g., `http://localhost:8000/static/gallery/foto1.jpg`).

### B. Base de Datos (PostgreSQL)
*   **Nuevo Modelo**: `GalleryImage` (Tabla SQL, no JSON) para gestión eficiente.
    *   `id`: UUID
    *   `tenant_id`: Para soporte multi-tenant.
    *   `file_path`: Ruta local.
    *   `public_url`: URL accesible por frontend.
    *   `user_description`: Descripción opcional del usuario.
    *   `ai_description`: Descripción generada por IA (Contexto visual).
    *   `ai_colors`: JSON/Array con códigos hexadecimales detectados.
    *   `status`: Enum (`processing`, `completed`, `failed`).

### C. Servicios y API
*   **Servicio de Análisis (`ImageAnalysisService`)**:
    *   Usará `langchain_openai` con `gpt-4o` (modelo multimodal).
    *   Input: Imagen (Base64 local).
    *   Output: JSON estructurado `{ description: string, colors: string[] }`.
    *   Ejecución: `BackgroundTasks` de FastAPI para no bloquear la respuesta de subida.
*   **Router (`/api/v1/gallery`)**:
    *   `POST /upload`: Recibe archivo + descripción, guarda en disco, crea registro DB y lanza tarea en segundo plano.
    *   `GET /`: Lista imágenes del tenant.
    *   `DELETE /{id}`: Elimina archivo y registro.

## 2. Frontend (React/Next.js)

### A. Cliente API
*   Crear `src/features/brand/api/gallery-api.ts` para interactuar con los nuevos endpoints.

### B. Componentes UI
*   **`GallerySection`** (`src/features/brand/components/live-preview/gallery-section.tsx`):
    *   **Vista de Grilla**: Tarjetas mostrando la imagen.
    *   **Estado de Carga**: Indicador visual ("Analizando con IA...") mientras el backend procesa.
    *   **Detalle/Hover**: Muestra la descripción del usuario y la generada por IA + paleta de colores.
    *   **Subida**: Área de Drag & Drop + Input de texto para descripción de uso.

### C. Integración en Brand Book
*   **`BrandBookPreview`**: Insertar `<GallerySection />` antes de la sección de Contacto.
*   **`BrandHealthSidebar`**:
    *   Agregar "Galería" al índice de navegación.
    *   Agregar regla de salud: Validar si existe al menos 1 imagen en la galería.

## 3. Flujo de Usuario
1.  Usuario va a "Sobre la Marca" -> Sección "Galería".
2.  Sube una imagen y (opcionalmente) escribe: "Foto del equipo para la página 'Nosotros'".
3.  La imagen aparece inmediatamente con estado "Procesando...".
4.  En segundo plano, la IA analiza la imagen.
5.  La UI se actualiza (polling o recarga) mostrando: "Foto de grupo diverso en oficina moderna. Colores: #FF5733, #C0C0C0".

## 4. Verificación
*   Subir una imagen y verificar que el archivo se guarda en disco.
*   Confirmar que la URL es accesible desde el navegador.
*   Verificar que la IA genera la descripción y colores correctamente.
*   Confirmar que el "Brand Health" aumenta al agregar una imagen.
