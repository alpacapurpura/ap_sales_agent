# Plan de Implementación: Landing Builder "Visionary Canvas" (Opción A)

Implementaremos la **Opción A** centrada en la generación automática experta mediante un Prompt Template robusto que produce una estructura XML estricta, lista para ser visualizada por el editor.

## 1. Análisis de Estructura (Backend)
Usaremos el arquetipo existente `THE_TRANSFORMER` (diseñado para Coaching/Cursos) como base del protocolo XML.
*   **Archivo Objetivo:** `backend/src/core/domain/landing_page/schema.py` (Referencia para los tags XML).
*   **Estructura del Protocolo XML:**
    ```xml
    <LandingPage archetype="THE_TRANSFORMER">
      <Theme>...</Theme>
      <Content>
        <Headline>...</Headline>
        <Subheadline>...</Subheadline>
        <StoryHook>...</StoryHook>
        <MethodName>...</MethodName>
        <Modules>
          <Module title="..." icon="...">...</Module>
        </Modules>
        <!-- Imágenes referenciadas por ID -->
        <HeroImageId>img_123</HeroImageId> 
      </Content>
    </LandingPage>
    ```

## 2. Creación del Prompt Template (`landing_coaching_grupal.j2`)
Crearé el archivo en `backend/src/core/prompts/templates/landing_coaching_grupal.j2` con las siguientes secciones críticas:

### A. Definición de Rol y Contexto
*   **Rol:** "World-class Direct Response Copywriter & UI/UX Expert".
*   **Instrucción:** "Actúa como un arquitecto de conversión. No pidas feedback, entrega la solución final basada en los datos proporcionados".

### B. Inyección de Conocimiento (Variables Jinja2)
*   `{{ brand_knowledge }}`: Tono de voz, historia del fundador, valores.
*   `{{ offer_details }}`: Promesa, precio, módulos, urgencia.
*   `{{ avatar_profile }}`: Dolores, deseos, objeciones.
*   `{{ media_assets }}`: Lista de objetos `{"id": "...", "description": "...", "type": "product|brand"}`.

### C. Lógica de Selección de Activos (Inteligente)
*   Instrucción explícita para el LLM: "Analiza el campo `description` de cada imagen en `media_assets`. Selecciona la imagen cuyo contenido visual mejor soporte la sección (ej. Foto del autor para la sección 'StoryHook'). Prioriza imágenes de tipo 'product' para el Hero".

### D. Definición Estricta del Output (Protocolo XML)
*   Proveeremos un esquema XML "One-Shot" (ejemplo completo) dentro del prompt para garantizar que el LLM respete la estructura anidada y los nombres de los tags.

## 3. Visualización y Edición (Simulación)
El output XML generado por este prompt está diseñado para ser:
1.  **Parseado:** Convertido automáticamente al objeto `LandingPageConfig` del backend.
2.  **Renderizado:** El frontend (`LandingPageEditor`) recibirá este objeto y mostrará la landing page "terminada".
3.  **Editado:** El usuario podrá clicar en cualquier texto o imagen (que ya viene pre-seleccionada por la IA) y cambiarla si lo desea, cumpliendo la promesa de "Visualizar en mi Editor".

2.  **Crear** el archivo `backend/src/core/prompts/templates/landing_coaching_grupal.j2` con la lógica detallada arriba.
3.  **Validar** que el template incluye todas las variables necesarias y la estructura XML correcta.
