Voy a mejorar la experiencia de edición de la Identidad Visual separando la "Extracción Automática" (Wizard) de la "Edición Manual" (Sidebar), tal como solicitas.

### 1. Nueva Arquitectura de Interacción
Implementaré dos modos distintos para la sección de visuales:
*   **Modo Edición (Sidebar):** Al hacer click en la paleta o tipografía, se abrirá el panel lateral derecho con el formulario completo para editar manualmente cada color y fuente.
*   **Modo Extracción (Wizard):** El botón "Extraer" abrirá el popup actual (que ya funciona bien) para escanear sitios web o logos.

### 2. Cambios en Componentes

#### A. Nuevo Formulario de Sidebar (`BrandVisualsForm`)
Crearé un nuevo formulario `src/features/brand/components/forms/brand-visuals-form.tsx` para el sidebar que permitirá editar:
*   **Colores:** Pickers para Primario, Acento, Fondo y Texto.
*   **Tipografía:** Selectores para Heading y Body fonts.
*   Este formulario se conectará al `EditSheetManager` para que el sidebar ya no aparezca "vacío" o nulo en esta sección.

#### B. Actualización de `VisualsSection` (Vista Previa)
Modificaré `src/features/brand/components/preview/visuals-section.tsx` para:
*   **Hacerla interactiva:** Todo el contenedor (o las secciones de color/tipo) será clickeable y abrirá el Sidebar.
*   **Botón "Extraer":**
    *   **Estado Vacío:** Mostrará un botón predominante "✨ Extraer Identidad de Web" centrado.
    *   **Estado Con Datos:** El botón pasará a ser un botón secundario ("ghost") ubicado discretamente (esquina superior o inferior), permitiendo re-escanear sin estorbar.

#### C. Lógica de Enrutamiento (`BrandStudioLayout`)
Actualizaré `brand-studio-layout.tsx` para manejar dos estados:
*   `editMode = 'visuals'` -> Abre el Sidebar (Edición Manual).
*   `editMode = 'visuals-wizard'` -> Abre el Popup (Extracción).
