# Implementar Tarjeta "Añadir Offer" (Add Card)

Voy a implementar el componente visual "Añadir a Nivel" siguiendo el patrón de diseño UX "Ghost Button/Card" solicitado, manteniendo la consistencia con Shadcn UI y el sistema de diseño actual.

## 1. Nuevo Componente: `AddOfferCard`

Crearé el archivo `src/features/offer-studio/components/dashboard/add-offer-card.tsx` con las siguientes características:

* **Dimensiones:** `h-[180px]` (idéntico a `OfferCard` para mantener el ritmo visual).

* **Estilo:** Borde discontinuo (`border-dashed`), fondo sutil (`bg-muted/50`), hover interactivo (`hover:border-primary`).

* **Contenido:** Icono `Plus` centrado y texto "Añadir a \[Nivel]".

* **Interacción:** `onClick` que abre el modal de creación existente.

## 2. Integración en el Dashboard

Modificaré `src/features/offer-studio/components/dashboard/offer-studio-dashboard.tsx` para integrar este componente en todas las vistas:

### Nivel 0 (Scroll Horizontal)

* Reemplazaré el botón "New" actual (pequeño y básico) por el nuevo `AddOfferCard`.

* Se envolverá en un `div` con ancho fijo (`w-[280px]`) para mantener la consistencia en el scroll horizontal.

### Niveles 1-6 (Grid Layout)

* Añadiré el `AddOfferCard` como el **último elemento** de la grilla.

* Se renderizará automáticamente después de los offers visibles (o como primer elemento si no hay offers).

* Esto eliminará la necesidad del botón "Empty State" actual cuando hay 0 offers, unificando la experiencia (siempre habrá un botón de añadir visible).

## 3. Resultado Esperado

* **Visual:** Una tarjeta con borde punteado al final de cada lista de ofertas.

* **UX:** Acceso directo y claro para crear ofertas en cualquier nivel sin buscar un botón pequeño en la cabecera.

* **Consistencia:** Respeto total a la paleta de colores y tipografía del tema actual (Visionarias).
