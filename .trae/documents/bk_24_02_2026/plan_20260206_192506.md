Voy a modificar el componente `OfferCard` para incluir el nombre del tipo de oferta (Offer Type) junto a la etiqueta del modelo de entrega (DIY, DWY, etc.).

### Pasos de Implementación:

1.  **Importar Metadatos**: Importaré `OFFER_TYPE_METADATA` desde `@/features/offer-studio/types/offer-metadata` en `offer-card.tsx`.
2.  **Obtener Etiqueta**: Recuperaré la etiqueta legible (`label`) correspondiente al `offer.type` actual usando el mapa de metadatos.
3.  **Agregar Badge**: Insertaré un nuevo componente `Badge` junto al existente.
    *   **Contenido**: Usará `typeMetadata.label` (ej. "Curso Auto-dirigido") en lugar del código (ej. "SELF_PACED_COURSE").
    *   **Estilo**: Usaré un estilo `secondary` o `outline` con un color neutro (gris/slate) para diferenciarlo visualmente de la etiqueta de "Modelo de Entrega" (que ya tiene colores semánticos como verde/azul).

### Resultado Esperado:
La tarjeta mostrará dos etiquetas en la parte superior:
`[DIY] [Curso Auto-dirigido]`
En lugar de solo:
`[DIY]`

Esto cumple con el requerimiento de mostrar el "nombre de negocio" y no el código técnico.
