# Plan de Implementación: Persistencia y Edición de Landing Pages

Sí, **podrás editarla**. He diseñado la solución para que sea editable, pero para completar el ciclo de "Guardar" y "Publicar" los cambios realizados en el editor, necesitamos añadir la persistencia en la base de datos y conectar el botón de guardar.

Aquí tienes el plan para habilitar la edición completa:

## 1. Actualización de Base de Datos (Backend)
Necesitamos añadir una columna al modelo `Product` (que es la tabla que representa las Ofertas) para guardar la configuración de la landing page.

*   **Archivo**: `backend/src/services/db/models/business.py`
*   **Cambio**: Añadir columna `landing_page_config = Column(JSONB, default={})`.
*   **Migración**: Crear un script de migración manual (Alembic) para aplicar este cambio en la base de datos PostgreSQL.

## 2. API de Guardado (Backend)
Implementar el endpoint para actualizar la configuración.

*   **Archivo**: `backend/src/api/routers/landing_ai.py`
*   **Nuevo Endpoint**: `PUT /api/v1/offers/{offer_id}/landing`
*   **Lógica**: Recibirá el JSON del editor (colores, textos, etc.) y actualizará la columna `landing_page_config` del producto correspondiente.

## 3. Conexión del Editor (Frontend)
Hacer que el botón "Publicar/Guardar" funcione de verdad.

*   **Archivo**: `frontend/src/features/landing-builder/components/editor/landing-editor.tsx`
*   **Integración**:
    *   Recibir `offerId` como prop.
    *   Al hacer clic en "Guardar", enviar una petición `PUT` al nuevo endpoint.
    *   Mostrar una notificación de "Guardado con éxito".

## 4. Conexión de la Página Pública
Asegurar que la página pública lea de la base de datos y no del MOCK.

*   **Archivo**: `frontend/src/app/(public)/p/[slug]/page.tsx`
*   **Cambio**: Reemplazar `MOCK_LANDING_DB` por una llamada real a `fetch(API_URL/offers/public/{slug})`.
*   **Backend**: Necesitaremos un endpoint público `GET /api/v1/public/offers/{slug}` que devuelva la configuración sin requerir autenticación.

---
**Resultado Final**:
Una vez ejecutado este plan, el flujo será:
1.  Generas la Landing con IA.
2.  Entras al Editor, cambias un texto o color.
3.  Haces clic en "Guardar".
4.  La página pública se actualiza instantáneamente con tus cambios.
