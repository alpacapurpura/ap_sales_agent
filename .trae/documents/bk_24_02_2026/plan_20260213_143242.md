# Refactorización de Generación de Landing Page a JSON

No es necesario utilizar XML ni parsers manuales (`_parse_xml_to_dict`). La solución moderna y robusta es utilizar las capacidades de **Salida Estructurada (Structured Output)** de los modelos actuales (GPT-4o), lo que garantiza que la IA devuelva un JSON válido que cumpla estrictamente con nuestros esquemas Pydantic.

## Cambios Propuestos

### 1. Backend: Actualizar `LandingGeneratorService`
- **Eliminar** el método `_parse_xml_to_dict`.
- **Definir** un modelo intermedio `TransformerPageGeneration` que combine los metadatos (`slug`, `seo`) y el contenido (`TransformerContent`).
- **Modificar** `generate_landing_page` para usar `self.llm.with_structured_output(TransformerPageGeneration)`.
- Esto simplifica el código y elimina la fragilidad del parsing de XML.

### 2. Prompt: Actualizar Plantilla Jinja2
- **Modificar** `backend/src/core/prompts/templates/landing_coaching_grupal.j2`.
- **Eliminar** todas las etiquetas XML y las instrucciones de formato XML.
- **Enfocar** el prompt únicamente en la calidad del copywriting y la lógica de ventas ("The Transformer").
- La estructura del JSON será impuesta automáticamente por el esquema Pydantic, por lo que no necesitamos describirla en el prompt.

## Beneficios
- **Robustez**: Elimina errores de `ET.ParseError` si la IA olvida cerrar una etiqueta.
- **Tipado Fuerte**: Garantiza que campos como listas o números vengan en el tipo correcto.
- **Limpieza**: Código más legible y mantenible.
