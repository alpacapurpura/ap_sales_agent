Voy a crear el skill `ux-ui-designer` diseñado específicamente para potenciar tu stack actual (Next.js + Tailwind v4 + Shadcn) con patrones de diseño disruptivos pero implementables.

El skill se estructurará de la siguiente manera:

### 1. Archivo Principal (`SKILL.md`)
Definirá la filosofía **"Disrupción Funcional"**:
- **Regla 80/20**: 80% patrones familiares (Shadcn estándar) para usabilidad, 20% innovación (micro-interacciones, layouts no convencionales) para el efecto "Wow".
- **Atomic Design Adaptado**: Mapeo de Átomos (Shadcn Primitives) -> Moléculas (Feature Components) -> Organismos (Bento Grids).
- **Protocolo de Reto**: Instrucciones para que el agente reciba un problema de negocio (ej. "Mejorar la conversión del checkout") y devuelva una propuesta visual y técnica.

### 2. Referencias Técnicas (`references/`)
- **`design-system.md`**: Documentación "viva" de tu configuración Tailwind v4 (variables CSS, temas) y primitivas Shadcn disponibles, para asegurar que las propuestas sean copiables y pegables.
- **`ux-patterns.md`**: Recetario de patrones 2025 validados para tu stack:
    - **Bento Grids Funcionales**: Layouts CSS Grid para dashboards densos.
    - **Generative UI**: Patrones para renderizar componentes dentro de chats de IA.
    - **Mobile-First Data**: Estrategias para mostrar tablas complejas en móviles (Sheet Stacking).

### 3. Plantillas (`assets/templates/`)
- **`ux-proposal.md`**: Un formato estandarizado para que el agente te presente soluciones. Incluirá secciones como:
    - *El Problema de Usuario*
    - *La Solución Estándar (Aburrida)*
    - *La Propuesta Disruptiva*
    - *Plan de Implementación (Código)*

### Pasos de Ejecución:
1.  Crear la estructura de directorios en `.trae/skills/ux-ui-designer`.
2.  Redactar `SKILL.md` con las instrucciones de comportamiento y "personalidad" de diseño.
3.  Generar los archivos de referencia con el conocimiento extraído de tu codebase (Tailwind v4, Shadcn).
4.  Empaquetar el skill para su uso inmediato.
