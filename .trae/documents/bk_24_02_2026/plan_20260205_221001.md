# Plan de Implementación: Selector Visual de Tipos de Oferta

Voy a mejorar la experiencia de creación de ofertas en el Nivel 1 (y todos los demás) implementando un selector visual con tarjetas informativas.

## 1. Definición de Metadatos (Frontend)
Crearé un nuevo archivo `frontend/src/features/offer-studio/types/offer-metadata.ts` que contendrá la "inteligencia" del negocio que actualmente solo vive en el backend (`offer_enums.py`).
- **Contenido**: Mapeo de cada `OfferType` con:
  - `label`: Nombre amigable (ej. "Curso Auto-dirigido").
  - `description`: Explicación clara para el usuario.
  - `delivery`: Modelo de entrega (DIY, DWY, DFY).
  - `level`: Nivel al que pertenece (para filtrar).

## 2. Actualización del Dashboard (`offer-studio-dashboard.tsx`)
Modificaré el modal de creación (`Dialog`) para reemplazar el input simple por un flujo de dos pasos o un formulario enriquecido:

1.  **Filtrado Inteligente**: Al hacer click en "Añadir a Nivel 1", el sistema filtrará los tipos disponibles usando la metadata creada.
2.  **Grid de Tarjetas**:
    - Renderizaré una grilla de tarjetas seleccionables.
    - Cada tarjeta mostrará:
      - **Título**: "Oferta Tripwire"
      - **Badge**: "DIY" (Do It Yourself)
      - **Descripción**: "Oferta irresistible de bajo costo..."
3.  **Selección**: El usuario selecciona una tarjeta (visual feedback: borde/color) y luego ingresa el nombre.
4.  **Creación**: Se enviará el `type` seleccionado a la API en lugar del default.

## 3. Resultado Esperado
Cuando hagas click en "Añadir" en Activación (N1), verás 4 tarjetas claras explicando qué es un Tripwire, un Curso, una Newsletter y un Producto Físico, permitiéndote elegir la estrategia correcta sin ser experto en la taxonomía interna.
