# Propuesta de Diseño UX/UI: "Guided Offer Architect"

## 1. Concepto: "El Arquitecto Inteligente"
El usuario no está "rellenando formularios", está **construyendo un activo de negocio**.
La interfaz debe comportarse como un consultor experto que se adapta al contexto. Si el usuario dice "Voy a hacer un Retiro de Lujo", el sistema esconde los campos de "Envíos por correo" y despliega los de "Logística de Hotel".

## 2. Estrategia de Layout (Bento Grid Adaptativo)
En lugar de un formulario lineal infinito, usaremos un **Grid de 3 Columnas** que cambia dinámicamente.

### Estructura Base (Desktop)
| Zona | Componente | Función |
| :--- | :--- | :--- |
| **Izquierda (2/3)** | `ContextualEditor` | El formulario principal que muta según el `OfferType`. |
| **Derecha (1/3)** | `LivePreviewCard` | Muestra en tiempo real cómo se verá la oferta para el cliente final (Precio, Promesa, Entregables). |
| **Bottom (Full)** | `AI_Suggestions` | (Futuro) Sugerencias de Copilot basadas en lo que escribes. |

## 3. Lógica de Campos Dinámicos (Polimorfismo Visual)
Basado en `offer_enums.py` y `schema.py`, he mapeado 4 arquetipos de interfaz.

### A. Arquetipo "Program" (Mentorías, Cursos, Cohortes)
*Se activa para: `HYBRID_MENTORSHIP`, `COHORT_BASED_COURSE`, `VIP_DAY_STRATEGY`.*
* **Foco**: Urgencia y Tiempo.
* **Campos Clave**:
    *   **Calendario Visual**: En lugar de inputs de texto, un selector de rango de fechas para "Inicio/Fin".
    *   **Escasez**: Switch gigante de "Cupos Limitados" con contador.
    *   **Interacción**: Selector visual de iconos para "Zoom en vivo" vs "Grabado".

### B. Arquetipo "Product" (Ebooks, Merch, Cursos Grabados)
*Se activa para: `TRIPWIRE_OFFER`, `PHYSICAL_MERCH`, `FREE_RESOURCE`.*
* **Foco**: Entrega Inmediata.
* **Campos Clave**:
    *   **Fulfillment Toggle**: "¿Es Físico o Digital?" (Cambia radicalmente el form).
    *   **Asset Uploader**: Zona de Drag & Drop para subir el PDF/Video (o poner el link).
    *   **Stock**: Input numérico simple para inventario.

### C. Arquetipo "Service" (Agencia, B2B, Retainer)
*Se activa para: `MONTHLY_RETAINER`, `DONE_FOR_YOU_AGENCY`.*
* **Foco**: Alcance y Contrato.
* **Campos Clave**:
    *   **SLA Slider**: Slider de tiempo para "Días de entrega".
    *   **Scope Builder**: Lista dinámica de "Qué incluye" (Checklist interactivo).
    *   **Onboarding**: Selector de "Formulario de Inicio" o "Llamada de Kickoff".

## 4. Patrones Educativos (La "Ayuda" al Líder de Nicho)
Dado que el usuario no es experto en ventas, usaremos **"Micro-Consultoría" en la UI**:

1.  **Smart Hints**: Debajo de cada campo, no solo explicar *qué* es, sino *por qué* importa.
    *   *Ejemplo (Precio)*: "Para un Nivel 2, el mercado suele pagar entre $500 y $2,000. Si cobras menos, podrías devaluar tu autoridad."
    *   *Implementación*: Usar la data de `OFFER_METADATA` (`hint` y `description`) en componentes `Alert` o `Tooltip`.
2.  **Visual Enums**: No usar `<Select>` nativos aburridos. Usar **Tarjetas Seleccionables** con iconos y descripciones ricas.
    *   *En lugar de:* Dropdown [DIY, DWY, DFY].
    *   *Verás:* 3 Tarjetas grandes explicadas: "Hazlo Tú Mismo (Ebook)", "Hazlo Contigo (Mentoría)", "Lo Hago Por Ti (Agencia)".
