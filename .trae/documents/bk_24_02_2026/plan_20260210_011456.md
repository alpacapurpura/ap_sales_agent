# Plan de Integración: Brand Visuals Manager

Para integrar el nuevo flujo de "Brand DNA" sin romper lo existente, adoptaremos una estrategia de **extensión no destructiva**. Añadiremos una nueva capa de datos (`visuals`) al esquema existente y la conectaremos al preview sin alterar los formularios actuales de identidad/contacto.

## 1. Actualización del Modelo de Datos (Backend & Frontend)

Actualmente, `BrandSettings` contiene `identity`, `team`, `authority_vault`, `contact`. Añadiremos una nueva sección `visuals`.

### Schema Update (`brand_schema.py` y `brand.ts`)
```python
class BrandVisuals(BaseModel):
    primary_color: str = Field("#000000", description="Color Primario (Hex)")
    accent_color: str = Field("#ffffff", description="Color Acento (Hex)")
    font_heading: str = Field("Inter", description="Fuente de Títulos")
    font_body: str = Field("Inter", description="Fuente de Cuerpo")
    style_preset: Optional[str] = Field(None, description="ID del Kit usado (ej: 'corporate')")

class BrandSettings(BaseModel):
    # ... existing fields ...
    visuals: BrandVisuals = Field(default_factory=BrandVisuals)
```

## 2. Componentes de UI (Frontend)

### A. El "Trigger" (Punto de Entrada)
En `BrandHeroSection` (el encabezado del preview), añadiremos un botón destacado: **"🎨 Definir Identidad Visual"**.

### B. El Wizard (`BrandVisualsWizard`)
Un componente `Dialog` que maneja los 3 caminos propuestos:
1.  **Sitio Web**: Si `settings.identity.website` existe, muestra "Usar colores de {website}". Si no, pide la URL.
    *   *Simulación*: Por ahora, usaremos una lista de mapeo simple (ej: si detecta "visionarias", sugiere morado/azul).
2.  **Logo**: Si `settings.identity.logo_url` existe, muestra "Extraer de Logo".
    *   *Implementación*: Usaremos `colorthief` (librería cliente) para extraer la paleta del logo en tiempo real.
3.  **Vibe Kits**: Una galería de 4 tarjetas pre-diseñadas (Corporate, Playful, Luxury, Minimal).

### C. El Inyector de Estilos (`ThemeInjector`)
Crearemos un componente invisible que lee `settings.visuals` y aplica variables CSS al contenedor del Preview.
*   Esto garantiza que **el resto de la app no se rompa**. Los estilos solo afectan al contenedor `#brand-book-preview`.
*   Usaremos CSS Variables locales: `--preview-primary`, `--preview-accent`.

## 3. Plan de Ejecución Paso a Paso

1.  **Backend**: Actualizar `brand_schema.py` para incluir `BrandVisuals`.
2.  **Frontend API**: Actualizar tipos en `lib/api/brand.ts`.
3.  **Wizard Component**: Crear `features/brand/components/visuals/brand-visuals-wizard.tsx`.
    *   Implementar lógica de selección (Web/Logo/Kits).
    *   Implementar `colorthief` para extracción de logo.
4.  **Integration**:
    *   Añadir el botón en `BrandHeroSection`.
    *   Conectar el `ThemeInjector` en `BrandBookPreview`.
    *   Asegurar que `useBrandSettings` guarde los nuevos datos.
