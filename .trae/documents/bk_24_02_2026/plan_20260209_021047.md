# Reestructuración de UX/UI en Offer Studio

## 1. Reorganización Visual (Layout)
- **Problema:** La disposición actual en columnas (`grid-cols-2`) hace que las secciones de "Mecanismo de Cierre" y "Precios" se vean apretadas y compitan por atención.
- **Solución:** Cambiar a un diseño vertical apilado (**Stack Vertical**).
    - **Arriba:** Tarjeta de "Mecanismo de Cierre" (Ancho completo). Esto dará aire a los selectores complejos (Garantía, Tipo de Cita) para que se lean claramente.
    - **Abajo:** Tarjeta de "Estrategia de Precios" (Ancho completo).

## 2. Rediseño del Módulo de Precios (Estilo Shopify)
Transformaremos la lista simple de inputs en un **"Editor de Estrategia de Precios"** inteligente.

### Nuevas Características:
1.  **Selector de Tipo de Plan (Tabs):**
    - Al crear un precio, podrás elegir visualmente entre:
        - 🟢 **Pago Único (Full):** Simple y directo.
        - 🔵 **Plan de Pagos (Split):** Para High Ticket (ej. 3 pagos de $X).
        - 🟣 **Suscripción:** Para membresías recurrentes.

2.  **Calculadora Automática:**
    - Si eliges "Plan de Pagos", el sistema calculará automáticamente:
        - *Monto de Cuota = (Total - Depósito Inicial) / N° Cuotas*.
    - Visualizarás el desglose financiero en tiempo real (ej. *"El cliente paga hoy $500 y luego 3 cuotas de $333"*).

3.  **Tarjetas de Precios Expandibles:**
    - En lugar de una tabla, cada precio será una **Tarjeta Inteligente**.
    - **Vista Resumida:** Muestra el nombre, monto total y etiqueta (ej. "3 Pagos").
    - **Vista Edición:** Se expande para ajustar los detalles finos.

4.  **Badges y Visuales:**
    - Etiquetas claras para identificar la opción "Más Popular" o "Ahorro".
    - Iconografía intuitiva para distinguir entre pagos únicos y financiados.

### Implementación Técnica:
- Modificar `offer-editor.tsx` para alterar el Grid Layout.
- Integrar componentes de `Tabs` y `Card` anidadas para el editor de precios.
- Conectar la lógica de cálculo con `react-hook-form` para que los números cuadren automáticamente.
