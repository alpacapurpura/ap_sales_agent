# Checklist

- [x] El Título del Offer está en un Header fijo superior que ocupa todo el ancho.
- [x] La Barra Lateral está debajo del Header y es "sticky" (no desaparece al scrollear).
- [x] La Barra Lateral se puede colapsar y expandir.
- [x] Al hacer clic en un ítem del menú lateral, la página hace scroll suave a la sección correspondiente.
- [x] Las secciones NO usan el estilo de "Cards" (bordes/sombras de caja).
- [x] Las secciones vacías muestran un diseño de invitación ("Empty State") con explicación y botón.
- [x] Las secciones con datos muestran un resumen limpio ("Editorial Style").
- [x] Al hacer clic en "Editar" o en el botón del estado vacío, se abre el panel lateral (Sheet) para editar.
- [x] La experiencia visual general es consistente con "Brand Studio".
