Brand Studio · Navegación estilo Finder

Screenshot actual muestra 3 columnas con jerarquía pero sin cohesión visual: anchos dispares, col2 parece tarjeta flotante, sin breadcrumb, sin chevrones, sin gradiente de profundidad. 4 propuestas exploran cómo traer el modelo Finder de macOS —cada columna es un nivel jerárquico claro— sin romper deep-linking ni URLs actuales.

Diagnóstico del estado actual

  1. Anchos dispares: col1=240px, col2=320px, col3=flex — las 3 no se sienten parte del mismo sistema.
  2. Col2 envuelta en rounded-md border — parece card flotante dentro de una columna, no una columna más.
  3. Header separa del split — "Posicionamiento · Brand Love Key…" corta la jerarquía en vez de reforzarla.
  4. Preview multi-línea compite con título — Finder usa 1 línea, label dominante.
  5. Sin chevrones que indiquen "este ítem tiene sub-nivel".
  6. Sin gradiente de profundidad — Finder diferencia columnas con tonos sutiles de fondo.
  7. Sin breadcrumb — el usuario pierde el rastro cuando col3 aparece.
Opción A+ · ★ Singletons (identidad, posicionamiento, narrativa…)

Finder 3-col · inline editor · reco abajo colapsable · grid multi-campo

Para secciones con un conjunto fijo de campos. Editor full-width left-aligned, grid responsive (1/2/3 col según ancho). Recomendaciones colapsables abajo.

  • Editor full-width sin max-width, grid se adapta al viewport
  • Campos cortos (text/url/enum) pueden ir lado a lado automáticamente
  • Textareas auto-grow, historia se lee sin scroll interno
  • Demo "Identidad" muestra grid multi-campo en acción
 Opción A+ · ★ Colecciones (buyer personas, equipo, testimonios…)

Finder 4-col · extra columna de instancias · mismo editor + reco

Extensión del patrón para secciones tipo colección. Inserta columna extra entre Secciones y Campos para elegir qué instancia (persona, miembro, testimonio) estás editando. Jerarquía se mantiene.

  • Copilot recibe contexto completo de la instancia (sugerencias más finas)
  • CTA "Crear nueva persona" siempre visible en top de la columna
  • Status bar por instancia muestra completitud
  • Route uniforme: /brand-studio/{section}/instance/{id}/{field}
 Opción A · Base

Finder Clásico · 3 columnas homogéneas

3 columnas iguales (260 / 340 / flex) con gradiente de profundidad, chevrones ">", breadcrumb en topbar, dots de estado. Solo el layout — sin refactor del editor.

  • Respeta URLs actuales /brand-studio/{section}/{fieldId}
  • Cambio más liviano — solo layout + tokens
  • Breadcrumb reemplaza SessionHeader
 Opción B · Pro

Finder + Preview Pane · 4 columnas

Finder puro de Mac: col1=secciones, col2=ítems, col3=preview read-only rápido, col4=editor cuando haces click en "Editar". Scaneás sin abrir el teclado.

  • Scan > edit — útil cuando tenés 40 ítems por sección
  • Edit mode es un paso explícito
  • Más ancho — ideal para pantallas ≥ 1440px
 Opción C · Compacto

Icon Rail + Tree expandible

Col1 colapsa a rail de 64px (solo iconos), col2 tree explorable N-level (secciones abren sub-items inline con chevrón que rota), col3 editor. Escala cuando agregás buyer-personas nested.

  • Maximiza ancho del editor
  • Permite nesting profundo (persona → dolores → subdolor)
  • Icon-rail con tooltip hover
 Opción D · Power user

Command Palette + Editor focused

Col1 permanece, col2 se convierte en palette buscable (Cmd+K), col3 es editor. Power users saltan en 2 keystrokes. La jerarquía se comunica por filtros/breadcrumb arriba del editor.

  • Búsqueda global > navegación manual
  • 2 columnas efectivas — editor respira
  • Requiere usuario familiarizado
