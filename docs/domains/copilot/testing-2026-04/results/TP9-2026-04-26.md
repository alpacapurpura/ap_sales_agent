## Failures + root cause + fix aplicado

### B18-TP9 — `card_kind: "plan_card"` schema gap BE Literal + FE union + FE dispatcher

- **Síntoma:** Backend emite block con `card_kind:"plan_card"` y `payload:{todos:[...]}` (S9.2 SSE confirmed). Frontend dispatcher `CardBlock.tsx:36` switch() NO tiene case `"plan_card"` → cae a `default` → `<NavigationCard action={action}/>`. NavigationCard espera `action.route` etc. — payload `{todos:[...]}` no tiene route. Render roto silencioso.
- **Trace evidence:**
  - `_write_todos_to_plan_card` (chat.py:317) returns dict con `card_kind:"plan_card"`.
  - BE Pydantic `CardBlock.card_kind` Literal en `domain/message_blocks.py:224` enumera 13 kinds — NO incluye "plan_card". Emitter bypassa Pydantic (raw dict).
  - FE `types/message-blocks.ts::CardKind` union enumera 11 kinds — NO incluye "plan_card".
  - FE `components/blocks/CardBlock.tsx:36` switch case ausente.
  - Componente legacy `PlanCard.tsx` existía pero esperaba shape obsoleto `{steps:[{order,label,toolName,estimatedTokens}], approve/reject buttons}` — no matches deepagents `{todos:[{content,status,active_form}]}` shape.
- **Root cause arquitectónico:** F2 (deep-agent harness) implementó el emisor backend (chat.py + write_todos synthesis) PERO nunca extendió:
  1. BE `CardBlock.card_kind` Literal con "plan_card".
  2. BE `card_payloads.py` registry con PlanCardPayload model.
  3. FE `CardKind` union con "plan_card".
  4. FE PlanCard.tsx para deepagents shape (legacy nunca conectado al dispatcher post-F2).
  5. FE CardBlock dispatcher case "plan_card".

  Arch test BE `test_card_payload_schemas.py::test_every_card_kind_is_registered` enforza CardBlock Literal ↔ registry symmetry — pasaba porque NI Literal NI registry tenían "plan_card", coherente entre sí pero ambos incompletos. Sin arch test BE↔FE schema parity, el gap pasó silencioso.
- **TDD fix dual:**
  - **(a) BE schema:**
    - `domain/message_blocks.py` — agrega "plan_card" al CardBlock.card_kind Literal.
    - `domain/card_payloads.py` — agrega `PlanCardTodo` BaseModel + `PlanCardPayload(_PayloadBase)` model + `"plan_card": PlanCardPayload` al `CARD_PAYLOAD_MODELS` registry. Comentario inline `B18-TP9`.
    - `tests/modules/copilot/test_card_payload_schemas.py` — nueva clase `TestPlanCardPayload` con 3 tests: valid passes / missing todos rejected / `validate_card_payload("plan_card", ...)` returns ok. RED→GREEN.
  - **(b) FE schema + dispatcher + component:**
    - `types/message-blocks.ts` — extiende `CardKind` union con "plan_card" + "inspiration_saved" + "memory_pinned" (también faltaban) + agrega `PlanCardTodo` interface + `PlanCardData` interface.
    - `components/PlanCard.tsx` — REWRITE del componente legacy (nunca conectado al dispatcher post-F2). Nuevo shape acepta `data: PlanCardData` con `todos[]`. Render: lista con `StatusIcon` per todo (Check completado / Loader2 in_progress / Circle pending) + counter `{completed}/{total}` en header + tachado en completed + active_form fallback en in_progress. NO approval workflow (informational, deepagents progresses sin user intervention).
    - `components/blocks/CardBlock.tsx` — nueva `case "plan_card"` antes del default → `<PlanCard data={block.payload as unknown as PlanCardData}/>`. Comentario inline `B18-TP9`.
    - `components/blocks/__tests__/CardBlock.plan-card.test.tsx` — 3 vitest cases: dispatch + render con todos[] + status icons + counter / all-pending initial state / defensive empty payload. RED→GREEN.
- **GREEN confirm:**
  - BE: `tests/modules/copilot/test_card_payload_schemas.py + test_plan_card_emission.py` 13/13 pass. BE arch full suite 571/571 pass.
  - FE: `CardBlock.plan-card.test.tsx` 3/3 pass + BlockDispatcher 6/6 pass. FE arch tests 38/38 pass. FE copilot suite 248/248 pass.
  - Live SSE re-trigger S9.2 confirma plan_card payload válida bajo nuevo schema.
- **Regression coverage:** El test FE garantiza que cualquier rebuild del dispatcher que pierda el case "plan_card" rompe CI. El test BE garantiza que agregar nueva card_kind sin model entry rompe.
- **Ratchet futuro:** considerar arch test BE↔FE card_kind parity (mirror BE Literal vs FE union) — heredado idea para F-pos.
