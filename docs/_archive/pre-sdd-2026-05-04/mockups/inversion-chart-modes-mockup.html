#7 · Edge case crítico Cuando objective != lo que el pixel reporta

Detección de "expectativa rota"

Si una campaña tiene objetivo de conversión pero el pixel no reporta nada en 7+ días, el dashboard lo grita.

⚠️

Tu campaña "Lanzamiento Curso 2026" tiene objetivo VENTAS pero no hay ventas registradas

La campaña está activa hace 9 días con objetivo OUTCOME_SALES, gastó PEN 280, pero tu pixel no registró ninguna compra. Esto suele ser un problema de configuración, no del producto.

Causa más probable (1): el pixel no está instalado en la página de checkout. Probá disparar manualmente el evento Purchase desde la consola del navegador.

Causa probable (2): el pixel está pero el evento "Purchase" no se dispara. Revisá tu integración con Shopify/Mercado Pago/Stripe.

Causa probable (3): nadie compró todavía (problema de mercado/oferta, no de setup).

Esta detección es automática: el sistema cruza el `objective` de cada campaña activa con los eventos reportados en `official_metrics`. Si hay una incongruencia > 7 días, levanta el warning. Sin acción del usuario.
