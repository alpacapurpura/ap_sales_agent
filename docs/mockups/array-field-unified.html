VARIANTE A

Enhanced Cards

Mejora drop-in del componente actual. Cards bordeadas, drag handle, chevron explícito, contador, duplicar, badge de validación, confirm delete inline. Ideal para: arrays de 2–10 items con 2–5 sub-campos (pilares, curriculum, plan StoryBrand, objections, value_stack, deliverables).

Pros
  • Drop-in — reemplaza ArrayInput sin cambiar schemas
  • Affordances claras: drag, chevron, duplicar, contador
  • Validación visual por item (completo / falta X / requiere Y)
  • Un item expandido a la vez (mantiene foco)
Contras
  • Vertical-heavy: con 20+ items requiere scroll largo
  • Para items con 10+ campos el expand domina el viewport
VARIANTE B

Accordion Denso

Filas compactas tipo accordion con resumen inline (título + metadata + badges). Mínimo chrome, máxima densidad. Soporta multi-expand opcional. Ideal para: arrays de 10–50+ items con 2–4 sub-campos (FAQs, testimonios, resources, client_logos, integrations, preferred_channels, tags).

VARIANTE C

Split Master-Detail

Lista a la izquierda (selector), editor completo a la derecha. Elimina empuje vertical y deja los formularios largos respirar. Ideal para: arrays con items complejos de 8+ campos (portfolio.cases, testimonials, venues, assets, team members).
