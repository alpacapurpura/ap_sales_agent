Homologación · 3 tiers obligatorios

Regla: todo campo debe tener al menos tier 1. Tier 2 y 3 progresivos según complejidad.

Tier Obligatorio Qué incluye Para qué campos
T1 ✓ Siempre label + hint (1 oración) Todos los campos de todos los schemas
T2 ✓ si complejo T1 + placeholder + examples (2–3) Campos libres / textareas / promesas / ofertas / pilares
T3 ✓ si estratégico T2 + formula + downstreamUses Campos que el agente cita o la landing auto-genera (voice_tone, promise, value_prop, RTBs)
