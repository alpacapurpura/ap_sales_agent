# Ideas — Raw input pre-validación

> Carpeta para "ideas locas" que aún NO son `opportunities/`. Inputs de Chris, brainstorming, intuiciones, links externos. Cero estructura formal requerida.

## Diferencia con `opportunities/`

| Carpeta | Estado | Estructura |
|---|---|---|
| `ideas/` | raw, sin validar, sin JTBD | libre — bullet, link, frase suelta |
| `opportunities/` | validada, JTBD claro, problem statement | template formal — Torres OST node |

Idea madura → migra a `opportunities/{slug}.md` cuando PM + Chris la trabajan junto en sesión `/pm`.

## Naming

`{slug-corto}.md`. Ej: `voice-agent-vapi-2027.md`, `referral-loop.md`, `ai-content-coach.md`.

## Workflow

1. Chris suelta idea → PM la captura aquí (sin refinar)
2. Cuando vale la pena explorar → PM + Chris trabajan en sesión `/pm`
3. Idea valida → migra a `opportunities/{slug}.md` con template completo
4. Idea descartada → mover a sub-carpeta `discarded/` con razón
