# Vision Comprimida — Nicolify

## Promesa

SaaS multitenant AaaS. Automatizar ciclo completo marketing/ventas (captación → calificación → cierre → fidelización) para creadores+pros+pequeños negocios mediante Agentes IA. Liberar tiempo. Sustituir equipo Mkt+Ventas a precio pasante.

## Quién

- Creadores contenido
- Infoproductores
- Negocios de Experto (servicios digitales/profesionales)

## Dolor núcleo

Sin tiempo + sin conocimiento técnico para gestionar embudo + integrar herramientas + escalar atención.

## Diferenciador

User = experto en SU negocio, NO en marketing. IA simplifica vía formularios guiados, auto-fill, scraping web, doc upload. Ingeniería inversa marca + oferta. Outputs ejecutables (assets, agente, dashboards) listos para usar.

## Núcleo arquitectónico

| Studio | Qué resuelve |
|---|---|
| Brand Studio | Captura identidad marca (scraping + reverse-engineering) |
| Offer Studio | Offer Ladder (gratis → low → high ticket) + Blueprints |
| Asset Generation | Landings + copies + flyers automáticos |
| Growth Studio | Bowtie funnel (vistas→leads→clientes→reventas) + action triggers |
| Sales Studio | Hub operativo (ver pipeline, intervenir) |
| Sales Agent | AI SDR autónomo (24/7, multi-canal) + agendamiento |
| Configuración | Conexiones (Meta, Shopify, pagos, calendar, email) |
| Copilot | Asistente in-app conversacional — interfaz primaria |

## Principios producto

1. **Copilot-first.** Toda funcionalidad operable conversacionalmente. UI es complemento, no único acceso.
2. **Agente como entregable.** No vendemos software, vendemos resultado (agente que cierra).
3. **Setup mínimo.** User aporta info marca/oferta. Sistema deduce el resto.
4. **Iterativo.** Calidad incremental. Walking skeleton primero, luego carne.
5. **LATAM neutro.** Tuteo, sin voseo. UI Latam-friendly, multi-currency, multi-timezone.
6. **Multitenant estricto.** `tenant_id` en todo query. Sin leak.

## Norte estrella

Tiempo real ahorrado al user por mes. Métrica derivada: % funnel automatizado por agente vs manual.

## Antipatterns explícitos

- No app para "managers de mkt experimentados" — perdería simplicidad
- No tool puramente Latam — copy neutro, sin localismos
- No reemplazar ingenio user — sólo eliminar fricción operativa
- No agente sin contexto marca/oferta — calidad pobre
