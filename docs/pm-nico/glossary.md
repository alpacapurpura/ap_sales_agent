# Glosario PM Nicolify

> Jerga negocio + producto. Dudas conceptuales → aquí primero.

## Producto

| Término | Definición |
|---|---|
| **Tenant** | Cliente de Nicolify. Aislamiento por `tenant_id`. |
| **AaaS** | Agent as a Service. Vendemos resultado del agente, no software. |
| **Studio** | Sección funcional de Nicolify (Brand/Offer/Growth/Sales). |
| **Bowtie funnel** | Modelo embudo: Vistas → Leads → Clientes → Reventas. Visual end-to-end. |
| **Offer Ladder** | Escalera valor: gratis (lead magnet) → low ticket → high ticket. |
| **Blueprint** | Template estructurado para definir oferta específica. |
| **SDR** | Sales Development Representative. Nuestro Sales Agent es AI SDR. |
| **Copilot** | Asistente in-app conversacional. Interfaz primaria. |
| **Action Trigger** | Acción ejecutable desde diagrama Bowtie (ej: crear campaña desde nodo). |

## Métodos PM aplicados

| Término | Definición |
|---|---|
| **JTBD** | Jobs-to-be-Done (Christensen) — qué "trabajo" contrata user al producto. |
| **OST** | Opportunity Solution Tree (Torres) — outcome → opportunities → solutions → experiments. |
| **Story Mapping** | Backbone horizontal (actividades user) × prioridad vertical (Patton). |
| **Now/Next/Later** | Roadmap sin fechas (Bastow). |
| **RICE** | Reach × Impact × Confidence / Effort. Score priorización. |
| **WSJF** | Weighted Shortest Job First. Cost-of-delay / job-size. |
| **Working Backwards** | Press release antes de construir (Amazon). |
| **PI** | Program Increment. Contenedor entrega tema-coherente. Variable scope. |
| **PR** | Product Requirement. Doc atómico entregable handoff. |
| **Walking Skeleton** | MVP funcional end-to-end mínimo. |
