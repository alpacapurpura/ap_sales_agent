## Fixes implemented

### Bug 1 — `generate_golden_candidates.py`: deterministic run_id (D8/D-A-15)

Added `_run_id_as_uuid(run_id: str) -> uuid.UUID` helper:
- If `run_id` is valid UUID string → parse and return directly (preserves D8 for real UUID run_ids)
- If `run_id` is arbitrary string (e.g. "repro-test-run") → derive UUID5 from `uuid.NAMESPACE_DNS` + string → stable across runs

Updated `_run_one_cell` to call `effective_run_id = _run_id_as_uuid(run_id)` and pass `run_id=effective_run_id` to `run_simulation`. Same seed_base + same string run_id → same UUID5 → same `_simulation_id` UUID5 → reproducible.

### Bug 2 — `generate_golden_candidates.py`: SQLA session injection

Updated `_run_one_cell` signature to accept `db_session: Session | None = None` (TYPE_CHECKING import only) and pass it to `run_simulation(db_session=db_session)`.

Updated `_main_async` to acquire a sync SQLAlchemy session before spawning cells:
```python
from src.core.database import SessionLocal
db_session = SessionLocal()
db_session.execute(text("SELECT 1"))  # probe
```

Session passed to all `_run_one_cell` calls. Session closed with `contextlib.suppress(Exception)` after `asyncio.gather` returns.

Graceful degradation: if DB unavailable → logs `generate_goldens.db_session_unavailable` warning → passes `db_session=None` (agent_bridge will terminate with SessionUnavailable as before, but at least the FAIL is observable). This matches Rule 5 of `tessl__graceful-degradation`.

### Bug 3 — `test_promote_golden.py:532`: AttributeError `module.__import__`

Replaced:
```python
_promo.__import__("generate_golden_candidates")._main_async(...)
```
With:
```python
import importlib
_gen_mod = importlib.import_module("generate_golden_candidates")
_gen_mod._main_async(...)
```

`sys.path.insert(0, str(_BACKEND_ROOT / "scripts"))` already present at line 528, so `importlib.import_module` resolves correctly.

### Bug 4 — `test_goldens_cost_bucket_invariant.py:52`: AttributeError `settings.DATABASE_URL`

Replaced:
```python
engine = create_engine(settings.DATABASE_URL.replace("+asyncpg", ""))
```
With:
```python
engine = create_engine(settings.database_url.replace("+asyncpg", ""))
```

`settings.database_url` is the `@property` on the `Settings` class (line 297 `src/core/config.py`) that builds the connection string. The test fixture now resolves correctly in setup.
