## Problem Summary

2 callback_handler tests failing post T-1 LiteLLM cost bridge:

```
tests/modules/sales_agent/observability/test_callback_handler.py::TestOnChatModelEnd::test_persists_row_with_sales_columns
  → TypeError: '>' not supported between NoneType and int  (cost_usd is None, not > 0)

tests/modules/copilot/observability/test_callback_handler_usage_fallbacks.py::TestUsageFallbacksFromResponseMetadata::test_response_metadata_token_usage_is_used
  → AssertionError: assert None == Decimal('0.0031637000')
```

Root cause: Mock LLMResult fixtures did not include `litellm_call_id` in response_metadata.
`_extract_litellm_call_id()` returned None → `pop_cost()` skipped → `cost_usd = None`.

## Fix (test-side only, per D-T1bis-1)

### 1. `tests/conftest.py` — added `prime_cost_bridge(call_id, cost)`

Helper function (not fixture) that calls `cost_recorder._stash(call_id, cost)` directly.
Simulates what `CostRecorderCustomLogger.log_success_event()` does in production.
Lifted to shared root conftest per D-T1bis-3 (pattern reused in 2 test files).

### 2. `tests/modules/sales_agent/observability/test_callback_handler.py`

- `_build_llm_response()`: added `litellm_call_id: str | None = None` param; injects into `response_metadata` when provided
- `test_persists_row_with_sales_columns`: generates UUID call_id, primes cache with `Decimal("0.001")`, passes call_id to `_build_llm_response()`

### 3. `tests/modules/copilot/observability/test_callback_handler_usage_fallbacks.py`

- `test_response_metadata_token_usage_is_used`: generates UUID call_id, primes cache with `Decimal("0.0031637000")` (value matches pricing snapshot), injects `litellm_call_id` into AIMessage `response_metadata`
