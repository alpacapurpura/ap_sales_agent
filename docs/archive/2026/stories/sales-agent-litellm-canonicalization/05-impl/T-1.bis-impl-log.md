## Root Cause Confirmed

`BaseAgentCallbackHandler._extract_litellm_call_id(response)` returns `None` when:
- Mock `LLMResult` response_metadata does NOT contain `litellm_call_id`
- Handler's `pop_cost(None)` call is skipped → `cost_usd = None`
- Tests asserting `cost_usd > 0` fail with `TypeError: '>' not supported between NoneType and int`

The production path works correctly:
1. `CostRecorderCustomLogger.log_success_event()` fires via LiteLLM → stashes cost via `_stash(call_id, cost)`
2. LangChain's `on_llm_end` fires → `_extract_litellm_call_id()` reads `litellm_call_id` from response_metadata → `pop_cost(call_id)` retrieves stashed cost

Test mocks don't go through LiteLLM → step 1 never fires → stash never populated.
