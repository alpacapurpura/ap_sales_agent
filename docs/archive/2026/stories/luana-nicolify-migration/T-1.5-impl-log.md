## Step 3 — Bulk editable install

Created `/home/chris/AISALESHT/backend/scripts/install_luana_core_editable.sh`.

**Key discovery during implementation:** initial sequential per-package install attempt
failed because pip cannot resolve cross-package dependencies when installing individually
(e.g., luana-core-analytics-engine requires luana-core-copilot, which isn't installed yet).
Solution: single pip invocation with all 25 `--editable <path>` args so pip resolves the
full dependency graph at once.

```bash
chmod +x /home/chris/AISALESHT/backend/scripts/install_luana_core_editable.sh
/home/chris/AISALESHT/backend/scripts/install_luana_core_editable.sh
```
