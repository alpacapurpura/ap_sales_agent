## 8. Cross-cutting fix Category C: test-mock string rewriter

**Problem:** libcst codemod only visits `ImportFrom` AST nodes. The 690 `mocker.patch("src.X")` calls embed paths as string literals — invisible to current codemod.

**Sample halts T-2 would hit:**
```python
# tests/modules/brand/test_personality_profile_updated_event.py
mocker.patch("src.shared.application.personality_event_handlers.prompt_loader")
# After import rewrite, the production code is at `luana_core_platform.application.personality_event_handlers`
# but the mock string still points to src.X → mocker.patch fails with AttributeError
```

**Fix Options:**

### Option C1 — Extend codemod to rewrite string literals (RECOMMENDED)

Add a new transformer to `scripts/codemod_be_imports.py`:

```python
class MockPatchStringRewriter(cst.CSTTransformer):
    """Rewrite `mocker.patch("src.X")` and `patch("src.X")` string literals.

    Handles:
    - mocker.patch("src.modules.X.Y")
    - mocker.patch.object("src.X")
    - patch("src.X")  (unittest.mock)
    - @patch("src.X")  decorator form
    """
    def leave_SimpleString(
        self,
        original_node: cst.SimpleString,
        updated_node: cst.SimpleString,
    ) -> cst.SimpleString:
        # Strip quotes
        raw = original_node.value
        if not (raw.startswith('"') or raw.startswith("'")):
            return updated_node
        inner = raw[1:-1]
        if not inner.startswith("src."):
            return updated_node

        # Match longest-prefix from _SORTED_MAPPING
        for src_prefix, target_prefix in _SORTED_MAPPING:
            if inner == src_prefix or inner.startswith(src_prefix + "."):
                suffix = inner[len(src_prefix):]
                new_inner = target_prefix + suffix
                quote = raw[0]
                self.changes.append(f"  mock {inner!r} → {new_inner!r}")
                return updated_node.with_changes(value=f"{quote}{new_inner}{quote}")
        return updated_node
```

Apply both transformers in order: `ImportRewriter` then `MockPatchStringRewriter`. Idempotent.

**Caveat — false positives:** Will also rewrite any string literal starting with `src.` regardless of context. Spot-check shows this is fine — no legitimate `"src.X"` strings outside mock patches/MAPPING tests/codemod itself.

**Pre-check before apply:** `--dry-run` mode logs every rewrite. Builder reviews first 100 changes manually. If suspicious → flag + halt.
