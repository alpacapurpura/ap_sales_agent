## Fix applied

**File:** `scripts/codemod_be_imports.py`

1. **Removed 3 Nicolify-local entries** (lines 50-52 original):
   - `src.modules.scheduling` → `nicolify_backend.modules.scheduling` ❌

   **Result:** Catch-all `src.shared.links` → `luana_core_platform.links` (line 94 original, kept) handles all `src.shared.links.ports.X` → `luana_core_platform.links.ports.X` correctly via prefix match.

3. **Updated self-check expected_rewrites** (lines 213-226 original):
   - Removed scheduling/advertising rewrite expectations (Nicolify-local now stay unchanged)
   - Updated brand/advertising port expected paths → `luana_core_platform.links.ports.X`
