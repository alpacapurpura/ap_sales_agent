       - ConnectionPortImpl(ConnectionPort):
         - __init__(self, db: Session) stores ChannelConnectionRepository(db)
         - async get_credentials(tenant_id, channel_type):
           a. Call self.repo.get_active(tenant_id, ChannelType(channel_type)) via asyncio.to_thread()
           b. If None: raise ConnectionRevokedException(f"No active connection for {channel_type}")
           c. Check if token is expired: look for `expires_at` in conn.credentials dict. If `expires_at` exists and is in the past (or within 5-minute buffer), attempt refresh
           d. To refresh: call `await self._refresh_token(conn)` which uses httpx to call the provider's token endpoint (e.g., Meta's /oauth/access_token, Google's /token). The refresh URL and client_id/client_secret come from conn.config or app settings
           e. On successful refresh: call self.repo.update_credentials(conn, new_credentials) via asyncio.to_thread() to persist the new access_token and expires_at
           f. On refresh failure (HTTP error, missing refresh_token): raise TokenRefreshFailed(f"Token refresh failed for {channel_type}", provider=channel_type)
           g. Return ConnectionCredentials(channel_type=channel_type, credentials=conn.credentials or {}, config=conn.config or {})
         - async _refresh_token(self, conn: ChannelConnectionModel) -> dict:
           - Determine provider from conn.channel_type
           - For Meta (META, FACEBOOK_PAGE, INSTAGRAM_ACCOUNT, META_ADS_ACCOUNT): POST to https://graph.facebook.com/v24.0/oauth/access_token with grant_type=fb_exchange_token
           - For Google (GOOGLE_ANALYTICS, YOUTUBE_ANALYTICS, GMAIL, GOOGLE_CALENDAR): POST to https://oauth2.googleapis.com/token with grant_type=refresh_token
           - For others: raise TokenRefreshFailed (refresh not implemented yet)
           - Returns updated credentials dict with new access_token and expires_at
         - async list_active_connections: calls self.repo.get_all_by_tenant(tenant_id) via asyncio.to_thread(); filters is_active=True; maps to ConnectionCredentials list
       - Note: Per user decision "ConnectionPort persists refreshed tokens: When a token is refreshed during extraction, the port (in connections module) saves the new token. Analytics never writes credentials."
