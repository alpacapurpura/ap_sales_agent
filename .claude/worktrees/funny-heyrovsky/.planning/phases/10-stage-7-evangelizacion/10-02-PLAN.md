Implement these SQL queries (all filtered by tenant_id):

a) **Active evangelists**: `SELECT cp.id, cp.full_name, rc.code, rc.is_active FROM customer_profiles cp JOIN referral_codes rc ON cp.id = rc.customer_id WHERE cp.tenant_id = :tid AND cp.lifecycle_stage = 'evangelist' AND rc.is_active = true`

b) **Per-evangelist referral stats**: For each evangelist's referral code, count sales where `metadata_info->>'referral_code' = :code`. Count total as referrals_sent, count where status='COMPLETED' as conversions, sum amount as revenue_attributed.

c) **K-Factor**:
   - evangelists_with_codes = count of active referral codes for tenant
   - total_referrals_sent = count of sales with any referral_code in metadata_info within date range
   - referral_conversions = count of COMPLETED sales with referral_code in date range
   - K = (total_referrals_sent / evangelists_with_codes) * (referral_conversions / total_referrals_sent)
   - Handle division by zero: return 0.0

d) **NPS summary**:
   - Count NpsResponseModel grouped by score ranges: promoters (score >= 9), passives (7-8), detractors (0-6)
   - Count NpsSurveyModel where status != 'pending' as surveys_sent
   - Average score from all responses
   - Standard NPS = ((promoters - detractors) / total) * 100

e) **Evangelist candidates**: `SELECT cp.id, cp.full_name, nr.score, nr.responded_at FROM nps_responses nr JOIN customer_profiles cp ON nr.customer_id = cp.id WHERE nr.tenant_id = :tid AND nr.score >= 9 AND cp.lifecycle_stage != 'evangelist' ORDER BY nr.score DESC, nr.responded_at DESC`

f) **UGC counts**: Count NpsResponseModel where `consent_public_use = true AND (testimonial_text IS NOT NULL OR testimonial_audio_url IS NOT NULL)`. Separate counts for written (testimonial_text not null) and audio (testimonial_audio_url not null).

g) **MiniFunnel**:
   - source_value = count DISTINCT customer_profiles where lifecycle_stage IN ('customer', 'evangelist') AND is_inactive = false
   - target_value = count where lifecycle_stage = 'evangelist'
   - conversion_rate = (target / source * 100) if source > 0 else 0

h) **Referral revenue**: Sum amount from sales with referral_code in metadata_info where status='COMPLETED' in date range.

Use `sqlalchemy.select()` with SQLAlchemy 2.0 syntax. Use `jsonb_extract_path_text` for JSONB queries (matching Phase 7 pattern). Import models with late-binding if needed to avoid circular imports.

```python
async def get_evangelization_metrics(self, tenant_id: UUID, start_date, end_date) -> EvangelizationDetailDTO:
    """Get Evangelization (Stage 7) detail panel metrics."""
    # 1. Check cache
    cache_key = f"evangelization:{tenant_id}"
    if self.cache:
        cached = self.cache.get(cache_key, stage="evangelization")
        if cached:
            return EvangelizationDetailDTO(**cached)

    # 2. Query repository
    from src.modules.analytics.infrastructure.repositories.evangelization_repository import EvangelizationRepository
    repo = EvangelizationRepository(self.db)
    data = await repo.get_evangelization_data(tenant_id, start_date, end_date)

    # 3. Compute bottlenecks
    bottlenecks = []
    k_factor = data.get("k_factor", 0.0)
    if k_factor < 0.5:
        bottlenecks.append(BottleneckDTO(
            type="low_k_factor", metric_label="K-Factor bajo",
            current_rate=k_factor, severity="critical", threshold=0.5,
            tip="Incentiva a tus mejores clientes a compartir su codigo de referido. Ofrece descuentos o beneficios exclusivos."
        ))
    elif k_factor < 1.0:
        bottlenecks.append(BottleneckDTO(
            type="low_k_factor", metric_label="K-Factor bajo",
            current_rate=k_factor, severity="warning", threshold=1.0,
            tip="Incentiva a tus mejores clientes a compartir su codigo de referido. Ofrece descuentos o beneficios exclusivos."
        ))

    nps_response_rate = data.get("nps_response_rate_pct", 0.0)
    surveys_sent = data.get("surveys_sent", 0)
    if surveys_sent > 0:
        if nps_response_rate < 15:
            bottlenecks.append(BottleneckDTO(
                type="low_nps_response", metric_label="Pocas respuestas NPS",
                current_rate=nps_response_rate, severity="critical", threshold=15,
                tip="Envia mas encuestas de satisfaccion. Los clientes que responden tienden a ser tus mejores promotores."
            ))
        elif nps_response_rate < 30:
            bottlenecks.append(BottleneckDTO(
                type="low_nps_response", metric_label="Pocas respuestas NPS",
                current_rate=nps_response_rate, severity="warning", threshold=30,
                tip="Envia mas encuestas de satisfaccion. Los clientes que responden tienden a ser tus mejores promotores."
            ))

    # 4. Assemble DTO
    result = EvangelizationDetailDTO(
        header_kpis=EvangelizationHeaderKpisDTO(**data["header_kpis"]),
        mini_funnel=MiniFunnelDTO(**data["mini_funnel"]),
        referidos=[EvangelistDTO(**e) for e in data.get("referidos", [])],
        candidatos=[CandidatoDTO(**c) for c in data.get("candidatos", [])],
        nps_summary=NpsSummaryDTO(**data["nps_summary"]),
        ugc_count=data.get("ugc_count", 0),
        ugc_written=data.get("ugc_written", 0),
        ugc_audio=data.get("ugc_audio", 0),
        bottlenecks=bottlenecks,
        last_updated=datetime.now(timezone.utc).isoformat(),
    )

    # 5. Cache result
    if self.cache:
        self.cache.set(cache_key, result.model_dump(), stage="evangelization")

    return result
```
