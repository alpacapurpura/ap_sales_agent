  <action>
    **MetaProvider** (`meta_provider.py`):
    - Implements BaseMetricsProvider, provider_name="meta"
    - `_extract_instagram_organic()`: Uses httpx to call `GET /v24.0/{ig_account_id}/insights?metric=reach&period=day` (sum daily values for total reach). Then `GET /v24.0/{ig_account_id}/media?fields=like_count,comments_count` for engagement breakdown. Returns ExtractedMetric(channel_slug="ig-organic", metric_name="reach") and ExtractedMetric(channel_slug="ig-organic", metric_name="engagement", extra={"likes": N, "comments": N, "shares": 0, "saves": 0})
    - `_extract_facebook_organic()`: Uses `GET /v24.0/{page_id}/insights?metric=page_impressions_unique` for reach, `page_post_engagements` for engagement. Uses `page_access_token` from credentials. Returns fb-organic channel_slug.
    - `_extract_meta_ads()`: Uses `GET /v24.0/act_{ad_account_id}/insights?fields=reach,clicks,spend,actions` at account level. Extracts conversions from `actions` array (purchase action types). Returns meta-ads slug with reach, clicks, conversions, spend metrics.
    - Use per-instance httpx.AsyncClient (NOT FacebookAdsApi.init() singleton per Phase 1 decision)
    - rate_limit_config: {"requests_per_minute": 200, "burst_size": 50}

    **GoogleAnalyticsProvider** (`google_analytics_provider.py`):
    - Implements BaseMetricsProvider, provider_name="google_analytics"
    - Uses existing `GoogleAnalyticsAdapter.run_report()` with dimensions=["sessionSource", "sessionMedium"], metrics=["sessions", "totalUsers"]
    - Wrapped in asyncio.to_thread() (sync Google SDK)
    - AI_REFERRER_DOMAINS = {"perplexity.ai", "chatgpt.com", "claude.ai", "copilot.microsoft.com", "gemini.google.com", "you.com", "phind.com"}
    - Segments rows: source in AI_REFERRER_DOMAINS -> ai-search-organic, source="google" medium="organic" -> google-organic, source="(direct)" medium="(none)" -> direct
    - Returns sessions and users metrics per channel_slug
    - rate_limit_config: {"requests_per_minute": 10, "burst_size": 5} (GA4 quota is low)

    **GoogleAdsProvider** (`google_ads_provider.py`):
    - Implements BaseMetricsProvider, provider_name="google_ads"
    - Uses GoogleAdsAdapter.run_gaql_query() with GAQL selecting campaign.advertising_channel_type, metrics.impressions, metrics.clicks, metrics.conversions, metrics.cost_micros
    - Separates rows by campaign.advertising_channel_type == "VIDEO" -> yt-ads slug, else -> google-ads slug
    - CRITICAL: Divide cost_micros by 1_000_000 for spend
    - Returns reach (impressions), clicks, conversions, spend per slug
    - Gracefully returns empty list if GOOGLE_ADS_DEVELOPER_TOKEN not in env

    **TikTokProvider** (`tiktok_provider.py`):
    - Implements BaseMetricsProvider, provider_name="tiktok"
    - `_extract_organic()`: Uses TikTokAdapter.get_organic_insights() for video_views (as reach) and engagement breakdown (likes, comments, shares). Returns tiktok-organic slug.
    - `_extract_ads()`: Uses TikTokAdapter.get_ads_report() for reach, clicks, conversions, spend. Returns tiktok-ads slug.
    - Gracefully handles missing credentials (returns empty list)

    **YouTubeProvider** (`youtube_provider.py`):
    - Implements BaseMetricsProvider, provider_name="youtube"
    - Uses existing YouTubeAnalyticsAdapter for views (as reach) and engagement (likes, comments)
    - Wrapped in asyncio.to_thread()
    - Returns yt-organic slug with reach and engagement metrics

    **CRMInternalProvider** (`crm_internal_provider.py`):
    - Implements BaseMetricsProvider, provider_name="crm_internal"
    - Queries JourneyEventModel (SQLAlchemy 2.0 syntax) filtering by tenant_id and event types related to outbound activity (event_name in ["outbound_contact", "outbound_call", "outbound_email"])
    - Counts total contacts and total responses (event_name in ["outbound_response", "outbound_reply"])
    - Returns cold-contact slug with contacts and responses metrics
    - NOTE: credentials dict not used (internal source); needs db session passed via credentials["db_session"] or similar

    **Registry update** (`registry.py`):
    - Add import and register_provider() calls for all 6 providers at module level
    - Use late-binding pattern: define a `_register_all()` function called at module import to avoid circular imports

    **Tests** (all test files use pytest + unittest.mock):
    - Each test file mocks the external API calls (httpx responses, GoogleAnalyticsAdapter.run_report, etc.)
    - Tests verify: correct channel_slug assignments, correct metric_name values, correct value extraction, cost_micros conversion, AI referrer domain segmentation, empty/error credential handling
    - Each provider gets at least 3 test cases: happy path, empty data, error/missing credentials
