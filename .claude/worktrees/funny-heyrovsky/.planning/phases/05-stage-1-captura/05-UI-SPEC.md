## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` | Panel background, page surface |
| Secondary (30%) | `hsl(var(--card))` / `hsl(var(--muted))` | ChannelGroup accordion areas, row hover state (`hover:bg-muted/50`) |
| Accent (10%) | `hsl(var(--primary))` | "Configurar costo" link text, mini funnel arrow, conversion rate percentage |
| Destructive | `hsl(var(--destructive))` | Not used in this phase (no destructive actions) |

Additional semantic colors (established patterns):
- Stale/warning: `text-yellow-600 dark:text-yellow-400` with `border-yellow-500/50` -- "Desactualizado" badge
- Connected: `text-green-600 dark:text-green-400` with `border-green-500/50` -- "Conectado" badge
- Muted text: `text-muted-foreground` -- secondary info, labels, timestamps
- Zero state: `text-muted-foreground` -- "0 leads" and hint text

Accent reserved for: "Configurar costo" action links, mini funnel conversion arrow/percentage, primary CTA interactions only

## Layout Spec

### CaptureDetail Panel Structure

```
[Panel Container: space-y-2]
  [Last Updated Timestamp: text-xs text-muted-foreground px-3 pb-1]
  [Panel Header KPIs: px-3 pb-2]
    Total Leads | Conversion Rate | CAL (Cost per Lead)
    Layout: flex items-center gap-6, each KPI as vertical stack (label on top, value below)
  [MiniFunnel: px-3 py-2 bg-muted/30 rounded-lg mb-2]
    "Visitantes (45,000)" -> arrow -> "Leads (8,500)" = "18.9%"
  [ChannelGroup: "Infraestructura Web"]
    groupType: web_infrastructure
    Summary: "Leads: {n} | Costo por Lead: ${n} | Conversion: {n}%"
    Channels: landing-form, mailerlite
  [ChannelGroup: "Agente AI Conversacional"]
    groupType: ai_agent
    Summary: "Leads: {n} | Costo por Lead: ${n} | Conversion: {n}%"
    Channels: ig-dm, fb-messenger, tiktok-dm, whatsapp-inbound
    Each row: primary "45 leads" + secondary "de 140 conversaciones"
  [ChannelGroup: "Canales Disponibles"]  (if any unconnected)
    groupType: available
    defaultOpen: false
```

### MiniFunnel Component Layout

```
[Container: flex items-center gap-3 px-3 py-3 bg-muted/30 rounded-lg]
```

## Data Contract (Frontend Types)

### New Types Required

```typescript
// Extend GroupType union
export type CaptureGroupType = 'web_infrastructure' | 'ai_agent' | 'available';

// Panel header KPIs
export interface CaptureHeaderKpis {
  totalLeads: number;
  conversionRate: number; // percentage 0-100
  costPerLead: number | null; // null = unconfigured
}

// Mini funnel data
export interface MiniFunnelData {
  sourceLabel: string;  // "Visitantes"
  sourceValue: number;
  targetLabel: string;  // "Leads"
  targetValue: number;
  conversionRate: number; // percentage
}

// Capture detail response
export interface CaptureDetail {
  headerKpis: CaptureHeaderKpis;
  miniFunnel: MiniFunnelData;
  webInfrastructure: TrafficGroup; // reuse existing type
  aiAgent: TrafficGroup;           // reuse existing type
  available?: AvailableChannels;   // reuse existing type
  period: string;
  lastUpdated?: string;
}
```

### ChannelMetric Extensions for Capture

The existing `ChannelMetric` interface supports this phase without modification:
- `metrics` array carries `leads`, `cost`, `conversion_rate` as `MetricValue` entries
- AI Agent channels add a `conversations` metric with value for the "de X conversaciones" line
- `costType` field already exists for NEUTRAL/EXPENSE/REVENUE classification
- `connected`, `stale`, `errorMessage`, `lastUpdated` all carry over
