## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, `gap-1` |
| sm | 8px | Compact element spacing, `space-y-2`, `gap-2` |
| md | 16px | Default element spacing, panel padding `p-4` |
| lg | 24px | Section padding, header KPI `gap-6` |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: Offer cards use `p-3` (12px) internal padding to match existing ChannelRow `px-3 py-2` rhythm. This is consistent with Phases 5-7 detail panels.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` | Panel background, page surface |
| Secondary (30%) | `hsl(var(--card))` / `hsl(var(--muted))` | Offer cards, tier group headers, MiniFunnel bg |
| Accent (10%) | `hsl(var(--primary))` | Conversion rate percentage in MiniFunnel, revenue total KPI emphasis |
| Destructive | `hsl(var(--destructive))` | Critical bottleneck banners only |

Accent reserved for:
- MiniFunnel conversion rate percentage (`text-primary`)
- Revenue total in header KPIs when positive
- No other elements

Additional semantic colors (from existing BottleneckBanner pattern):
- Warning: `bg-yellow-50 border-yellow-200 dark:bg-yellow-950/20` — warning bottleneck banners, inline "Alerta" badge
- Critical: `bg-red-50 border-red-200 dark:bg-red-950/20` — critical bottleneck banners, inline "Critico" badge
- Revenue positive: `text-emerald-600 dark:text-emerald-400` — revenue amounts in offer cards (green for money earned)
- Muted: `text-muted-foreground` — secondary lines, source breakdowns, labels

## Layout Specification

### SalesDetail Panel Structure

```
[Timestamp]                                          text-xs muted px-3 pb-1
[Header KPIs: Revenue Total | Nuevos Clientes | CAC] flex gap-6 px-3 py-2
[MiniFunnel: Oportunidades -> Ventas = X%]           bg-muted/30 rounded-lg px-3 py-3
[BottleneckBanner(s)]                                space-y-2 px-3 (0-2 banners)
[RevenueGroupHeader: Adquisicion]                    px-3 py-2 font-semibold
  [TierGroup: Low Ticket]                            Accordion, defaultOpen
    [OfferCard: Offer A]                             rounded-lg border p-3
    [OfferCard: Offer B]
  [TierGroup: Mid Ticket]
    [OfferCard: Offer C]
  ...empty tiers hidden...
[RevenueGroupHeader: Expansion]                      px-3 py-2 font-semibold
  [TierGroup: ...]
    [OfferCard: ...]
[Available Channels (if any)]                        ChannelGroup defaultOpen=false
```

Container: `space-y-2` (matches OpportunityDetail)

### RevenueGroupHeader Layout

```
[Group Icon] [Group Name] — [$Revenue CURRENCY (~$X USD)] — [N clientes] — [XX% del total]
```

- Full width, `px-3 py-2`
- Group name: `text-sm font-semibold`
- Revenue: `text-sm font-semibold text-emerald-600 dark:text-emerald-400 tabular-nums`
- Customer count + percentage: `text-xs text-muted-foreground`

### TierGroup Layout

Accordion (shadcn) wrapping offers in a tier:

```
[Tier Label: "Low Ticket"]        text-xs font-semibold uppercase tracking-wide text-muted-foreground
  [OfferCard]
  [OfferCard]
  ...
```

- Trigger: `py-2 px-3`
- Content: `space-y-2`
- defaultOpen: `true` for tiers with sales, `false` for tiers with only $0 offers

### OfferCard Layout

```
+----------------------------------------------------------+
| [Emoji] Offer Public Name       $45,000 MXN (~$2,500 USD)|  Line 1: primary
|         Shopify: 60 | Agent: 15 | Manual: 5              |  Line 2: source breakdown
|         45 nuevas ($13,500) | 15 renovaciones ($4,500)   |  Line 3: subscription split (conditional)
+----------------------------------------------------------+
```

- Container: `rounded-lg border p-3 hover:bg-muted/50 transition-colors`
- Line 1: `flex items-center justify-between`
  - Left: offer emoji + `text-sm font-medium` name + `text-xs text-muted-foreground` sales count (e.g., "120 ventas")
  - Right: `text-sm font-semibold text-emerald-600 dark:text-emerald-400 tabular-nums` revenue with dual currency
- Line 2: `text-xs text-muted-foreground` — source breakdown (only sources with count > 0)
- Line 3 (conditional, subscription offers only): `text-xs text-muted-foreground` — new vs renewal split

Card border: `border` (uses `hsl(var(--border))`)

### Offer Card Emoji Map

Emojis assigned by tier (not hardcoded per offer type — dynamic):

| Tier | Emoji |
|------|-------|
| Low Ticket | `$` (dollar sign, plain text) |
| Mid Ticket | `$$` |
| High Ticket | `$$$` |
| Recurrente | `sync icon` (lucide `RefreshCw` 16px) |

Rationale: Tier-based emojis avoid breaking when new OfferTypes are added. Revenue tiers are stable.

## Bottleneck Thresholds

### Low Conversion Rate (SQL -> Customer)

| Severity | Threshold | Rationale |
|----------|-----------|-----------|
| Normal | >= 20% | Industry average for B2C creator economy: 15-30% close rate |
| Warning | 10-20% | Below average; process friction likely |
| Critical | < 10% | Severe drop-off; immediate attention needed |

Bottleneck type: `low_conversion_rate`

### High CAC Ratio (CAC / Average Order Value)

| Severity | Threshold | Rationale |
|----------|-----------|-----------|
| Normal | CAC < 33% of AOV | Healthy 3:1 LTV:CAC proxy |
| Warning | CAC 33-50% of AOV | Margins compressed |
| Critical | CAC > 50% of AOV | Unsustainable; spending more than half of revenue to acquire |

Bottleneck type: `high_cac_ratio`

Source: SaaS/creator economy benchmarks — 3:1 LTV:CAC is standard healthy ratio. Since we don't have full LTV yet (Phases 9-10), AOV serves as conservative proxy.

```tsx
<div className="p-4 text-sm text-muted-foreground">
  No se pudieron cargar los datos de ventas. Verifica tu conexion e intenta nuevamente.
</div>
```

### Empty (No Offers)

Full-width centered empty state with:
- Heading: `text-sm font-semibold`
- Body: `text-xs text-muted-foreground`
- Link: `text-xs text-primary underline` pointing to Offer Studio

### Empty (Offers Exist, No Sales)

Render full offer catalog from Offer Studio with `$0 — 0 ventas` per card. Tiers with all-zero offers collapsed by default.

## Value Level to Tier Mapping (Backend Reference)

This mapping lives in backend only. Frontend receives pre-grouped tiers.

| Tier Key | Tier Label | Value Levels Included |
|----------|-----------|----------------------|
| `low_ticket` | Low Ticket | LEVEL_1_LOW_TICKET |
| `mid_ticket` | Mid Ticket | LEVEL_2_MID_TICKET |
| `high_ticket` | High Ticket | LEVEL_3_HIGH_TICKET, LEVEL_5_ULTRA_HIGH, LEVEL_6_CORPORATE |
| `recurrente` | Recurrente | LEVEL_4_RECURRING |

- LEVEL_0_FREE excluded (lead magnets, no revenue)
- Unknown/new levels default to `high_ticket` (safe fallback per CONTEXT.md)
- Well-structured comments required in mapping code for future AI/dev maintenance
