   - Calculate the cutoff datetime: `datetime.utcnow() - timedelta(hours=hours)`

     - Fetch subscriber activity: `GET /campaigns/{campaign_id}/reports/subscriber-activity?filter[type]=opened&limit=100` and `filter[type]=clicked&limit=100`

   - Return the full list of activity dicts

   - Mailerlite API pagination: response has `data` array and `meta.next_cursor`. For v1, limit=100 per page is sufficient (most campaigns have <100 unique subscribers interacting). Do NOT paginate — keep it simple.

   - Campaign response shape: `{"data": [{"id": "...", "name": "...", "status": "sent", "finished_at": "..."}]}`
   - Subscriber activity response shape: `{"data": [{"subscriber": {"email": "..."}, "type": "opened|clicked", "created_at": "..."}]}`

   - Log at info level: "Fetching Mailerlite campaign activity for last {hours} hours, found {N} campaigns"
