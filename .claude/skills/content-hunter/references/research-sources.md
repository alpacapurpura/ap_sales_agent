## 4. Search Query Templates

Ready-to-use queries for `WebSearch`. Replace `{niche}`, `{platform}`, `{country}`, `{topic}` with client specifics.

### Cross-Niche Viral Hunt
```
"{niche} viral {platform} 2025 2026"
"most shared {topic} content {country}"
"trending {platform} format {country} site:reddit.com"
"viral hook formula {platform} examples"
"{different_niche} viral reel breakdown"
```

### Same-Niche Saturation Check
```
"{client_niche} {platform} content trends 2026"
"{competitor_name} {platform} top posts"
"{client_niche} overused content formats"
"{client_niche} {platform} what everyone is posting"
"site:tiktok.com {client_niche} viral"
```

### Format & Hook Discovery
```
"best performing {platform} hooks {year}"
"content arc types that go viral"
"{platform} algorithm changes {year} what works"
"carousel formats that get saves {platform}"
"hook formulas for {platform} reels"
```

### Geographic Diversity
```
"{topic} viral {platform} {country_different_from_client}"
"{niche} content creator {country} trending"
"{topic} marketing trends Latin America OR Spain OR Brazil"
"{niche} {platform} viral Asia OR Europe OR Africa"
```

### Meta Ad Library Queries
```
site:facebook.com/ads/library "{competitor_name}"
site:facebook.com/ads/library "{client_niche}" active
"{client_niche}" meta ads top performing {year}
```

## 5. Research Protocol

When hunting, follow this sequence:

1. **Start cross-niche** (queries from section 4.1) — minimum 3 different niches
2. **Check same-niche saturation** (queries from section 4.2) — document what's overused
3. **Discover formats** (queries from section 4.3) — platform-specific structures
4. **Force geographic diversity** (queries from section 4.4) — minimum 2 countries different from client's
5. **Check competitor ads** (queries from section 4.5) — know what's already running

For each promising reference found:
- Note: platform, niche, country, estimated reach (views/shares/likes), hook used, format
- Save URL or describe content if URL unavailable
- Flag obvious saturation signals immediately
