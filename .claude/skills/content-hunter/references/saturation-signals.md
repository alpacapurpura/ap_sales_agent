# Saturation Signals

How to detect when a content formula is overused. Used in Phase 2 (layer 2) and Phase 4 (validation).

---

## 1. Six Saturation Indicators

| # | Signal | How to Detect | Severity |
|---|---|---|---|
| 1 | **Engagement Decay** | Same format used by multiple creators shows declining likes/comments ratio over 4-8 weeks | High — algorithm is deprioritizing |
| 2 | **Copy Explosion** | 10+ creators in the same niche using the exact same hook/format in the last 30 days | Critical — audience fatigue guaranteed |
| 3 | **CTR Decline** | Ad formats using the structure show declining click-through rates in Meta/TikTok Ad Libraries | High — audience has developed banner blindness |
| 4 | **Negative Sentiment** | Comments shift from engagement to "not this again", "so original", eye-roll emojis | Critical — actively hurting brand perception |
| 5 | **Algorithm Deprioritization** | Platform explicitly announces reduced reach for format (e.g., TikTok deprioritizing watermarked Reels) | Critical — structural disadvantage |
| 6 | **Parody Emergence** | Parodies and satire of the format appear — the format has become a meme itself | Terminal — the format is dead for serious use |

**Severity scale:**
- **Critical** = Do NOT use this format. SKIP immediately.
- **High** = Usable only with heavy SCAMPER transformation (minimum 3 operations).
- **Medium** = Proceed with caution, apply at least 2 SCAMPER operations.

## 2. Content Format Lifecycle

Every format follows this curve. Target entry at Innovation or Early Adoption.

```
Virality
  ^
  |        *  Growth
  |       * *
  |      *   *  Peak
  |     *     *
  |    *       *  Saturation
  |   *  Early  *
  |  * Adoption  *  Decline
  | *             *
  |* Innovation    *  Parody/Death
  +-------------------------> Time

  TARGET ZONE         DANGER ZONE
  [Innovation]        [Peak → onward]
  [Early Adoption]
```

| Stage | Characteristics | Action |
|---|---|---|
| **Innovation** | <5 creators using it, no niche-specific copies, feels genuinely new | HUNT THIS. Maximum first-mover advantage. |
| **Early Adoption** | 5-20 creators, mostly in other niches, audiences react with surprise | HUNT THIS. Strong adaptation window. |
| **Growth** | 20-50 creators, starting to appear in your niche, still getting good engagement | ADAPT with caution. Apply 2+ SCAMPER operations. |
| **Peak** | 50+ creators, your competitors are doing it, engagement still decent but plateauing | AVOID unless you can radically transform (3+ SCAMPER ops + combination). |
| **Saturation** | Everyone is doing it, engagement declining, comments becoming generic | SKIP. Redirect to new reference. |
| **Parody/Death** | Parodies exist, format is a joke, using it un-ironically damages credibility | SKIP. The format is dead. |

## 3. How to Verify Saturation

Step-by-step process for checking a specific format/hook:

1. **Search the format on the client's platform**
   - Query: `"{hook_type}" OR "{format_name}" site:{platform}.com {client_niche}`
   - Count results from the last 30 days

2. **Check competitor feeds**
   - Visit top 5 competitors' profiles
   - Scan last 30 posts for the same structure
   - If 2+ competitors used it recently → flag as Peak or Saturated

3. **Evaluate engagement trajectory**
   - Find 3+ examples of the format in the niche
   - Compare engagement rates (likes+comments / followers) across time
   - Declining trend → High saturation signal

4. **Read the comments**
   - Negative sentiment patterns (Signal #4) are the clearest indicator
   - Even one "not this again" on a mid-sized account is a red flag

5. **Check platform announcements**
   - Search: `"{platform} algorithm update {year} {format}"`
   - Any deprioritization signals → Critical

## 4. What to Do When Saturated

When a promising reference turns out to be saturated in the client's niche:

| Option | When to Use | How |
|---|---|---|
| **SCAMPER: Modify** | Format is at Growth/Peak but the underlying psychology still works | Change format entirely (video → carousel), keep the hook psychology |
| **SCAMPER: Reverse** | Format is saturated but the OPPOSITE take hasn't been done | Flip the premise ("Why I STOPPED doing [saturated thing]") |
| **SCAMPER: Combine** | Format is saturated alone but hasn't been mixed with another structure | Merge with a fresh format from a different niche |
| **Abandon & Re-hunt** | Format is at Saturation or Parody stage | Return to Phase 2, hunt in a completely different niche or geography |

**Golden rule:** If a format is saturated, the audience PSYCHOLOGY behind it usually isn't. Extract the psychological trigger (STEPPS dimension) and find a fresh vehicle for it.
