# Virality Frameworks

Reference material for Phase 3 (Deconstruct). Score every reference before adaptation.

---

## 1. STEPPS Scoring (Jonah Berger — "Contagious")

Rate each dimension 0-3. Only advance references scoring **>= 10/18**.

| Dimension | 0 — Absent | 1 — Weak | 2 — Present | 3 — Strong | Quick Test |
|---|---|---|---|---|---|
| **S**ocial Currency | Nothing shareable | Mildly interesting | Makes sharer look smart/cool | Insider knowledge, remarkable stat, status signal | "Would someone screenshot this to flex?" |
| **T**riggers | No environmental cue | Rare trigger | Occasional daily cue | Frequent, unavoidable trigger (morning routine, payday, Monday) | "What everyday thing reminds you of this?" |
| **E**motion | Neutral/informational | Low-arousal (sadness, contentment) | Medium-arousal (humor, surprise) | High-arousal (awe, anxiety, anger, excitement) | "Does this make you FEEL something in <3 seconds?" |
| **P**ublic | Private behavior | Semi-visible | Observable if you look | Built-in visibility (duets, stitches, challenges, wearable) | "Can others see someone engaging with this?" |
| **P**ractical Value | No takeaway | Vaguely useful | One clear tip | Actionable framework they'll save/share | "Would someone send this to a friend saying 'you need this'?" |
| **S**tories | No narrative | Weak anecdote | Clear before/after | Trojan horse — the message IS the story | "Can you retell this without losing the core message?" |

**Scoring thresholds:**
- 14-18: Exceptional viral potential — prioritize
- 10-13: Strong foundation — adapt with confidence
- 6-9: Needs significant SCAMPER work to compensate weak dimensions
- 0-5: Skip — not worth adapting

## 2. Hook Formulas (7 Types)

Every piece of content lives or dies in the first 1-3 seconds. Match hook type to content goal.

| # | Hook Type | Template | Best For | Fails When | Platform Fit |
|---|---|---|---|---|---|
| 1 | **Contrarian** | "Stop doing [common advice]. Here's why..." | Thought leadership, hot takes | Claim is unsupported or clickbait | Reels, TikTok, Twitter/X |
| 2 | **Mistake/Warning** | "[X] mistakes [audience] make with [topic]" | Educational, problem-aware audience | Mistakes are obvious/generic | Carousels, Reels, YouTube |
| 3 | **Numbered List** | "[N] [things] to [desired outcome]" | Practical value, saves | N is too high (>7) or items are weak | Carousels, Threads, YouTube |
| 4 | **Time-Based** | "In [time], I [achieved result]. Here's how..." | Transformation, social proof | Timeline is unbelievable or result is vague | Reels, TikTok, Stories |
| 5 | **Question** | "Why does [surprising thing] happen?" / "What if you could [desire]?" | Curiosity gap, awareness stage | Question has an obvious answer | Reels, TikTok, Carousels |
| 6 | **Problem-to-Payoff** | "I was [pain point]. Then I [discovery]. Now [result]." | Testimonial, case study | Sounds like an infomercial | Reels, TikTok, YouTube |
| 7 | **Counterintuitive** | "The [unexpected thing] that [unexpected result]" | Myth-busting, pattern interrupt | Logic doesn't hold up on reflection | All platforms |

**Hook rules:**
- First 3 words carry 80% of the weight — front-load the tension
- Visual hook must match verbal hook (pattern interrupt in both channels)
- Never start with "Hey guys", brand name, or logo — earn attention first
- Test: cover the hook, read the rest — if it still makes sense, the hook is decorative (bad)

## 3. Content Arcs

The structural shape of the content from hook to CTA.

| Arc | Structure | Best For | Duration Sweet Spot |
|---|---|---|---|
| **Myth-Busting** | Common belief → evidence against → truth → reframe | Contrarian hooks, authority building | 30-60s Reel/TikTok |
| **Transformation** | Before state → turning point → process → after state | Testimonials, case studies, social proof | 30-90s Reel, YouTube Short |
| **Tutorial Cascade** | Problem → Step 1 → Step 2 → Step 3 → Result | Practical value, saves/shares | Carousel (5-7 slides), 60s video |
| **Day-in-the-Life** | Morning context → key activity → insight/lesson → close | Relatability, behind-the-scenes | 30-60s Reel/TikTok |
| **Challenge** | Setup rules → attempt → obstacles → result (win or fail) | Engagement, duets, UGC | 15-60s TikTok/Reels |
| **Behind-the-Scenes** | Reveal process → show mess/real → contrast with polished result | Authenticity, trust-building | Stories series, 30-60s Reel |
| **Hot Take** | Bold statement → evidence stack (3 points) → reframe → CTA | Engagement (agree/disagree), saves | 15-30s Reel, Twitter thread |
| **Education** | "Most people think X" → "But actually Y" → "Here's why" → "Do this instead" | Authority, practical value | Carousel, 30-60s video |

## 4. Platform Constraints

Hard limits that override creative ambitions.

| Platform | Format | Duration/Size | Sweet Spot | Algorithm Signal |
|---|---|---|---|---|
| **Instagram Reels** | 9:16 vertical | Up to 90s | 30-60s | Watch-through rate, shares, saves |
| **TikTok** | 9:16 vertical | Up to 10min | 15-60s | Watch-through rate, comments, shares |
| **YouTube Shorts** | 9:16 vertical | Up to 60s | 30-50s | Swipe-away rate (inverse), subs gained |
| **Instagram Carousel** | 1:1 or 4:5 | Up to 20 slides | 5-10 slides | Dwell time per slide, saves, shares |
| **Instagram Stories** | 9:16 vertical | 15s per segment | 3-7 segments | Tap-forward rate (inverse), replies |
| **Twitter/X Thread** | Text + media | 280 chars/tweet | 5-8 tweets | Bookmarks, retweets, quote tweets |
| **LinkedIn Post** | Text + 1 image/carousel | 3000 chars | 800-1500 chars | Dwell time, comments (esp. early) |

## 5. GaryVee Reverse Pyramid (Atomization)

One pillar piece becomes 10+ micro-pieces across platforms.

```
                    [PILLAR CONTENT]
                 (Long-form: YouTube, Blog, Podcast, Live)
                          |
              +-----------+-----------+
              |           |           |
        [MICRO-VIDEO] [CAROUSEL] [QUOTE CARDS]
        (Reels/TikTok) (IG/LinkedIn) (Stories/Twitter)
              |           |           |
        [AUDIO CLIP] [THREAD]   [MEME/GIF]
        (Podcast clip) (Twitter)  (Stories/Reels)
```

**Atomization rules:**
1. Extract the single most emotional/practical moment from pillar
2. Each micro-piece must stand alone (no "as I said in my last video...")
3. Adapt format to platform — don't just crop, restructure
4. Each micro-piece gets its own hook optimized for that platform
5. Stagger publishing over 5-7 days (not all at once)
