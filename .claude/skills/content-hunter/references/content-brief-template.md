# Content Brief Template

Deliverable format for Phase 5. One brief per approved idea.

---

## 1. Content Brief

```markdown
## Content Brief: [Title / Working Name]

### Origin
- **Reference:** [URL or description of original content]
- **Original niche:** [niche] | **Country:** [country]
- **SCAMPER operations applied:** [list 2-3 operations with one-line explanation each]
- **Steal Rules satisfied:** [list which of the 6 rules this adaptation follows]

### STEPPS Score: [X]/18
| S. Currency | Triggers | Emotion | Public | P. Value | Stories |
|---|---|---|---|---|---|
| [0-3] | [0-3] | [0-3] | [0-3] | [0-3] | [0-3] |

**Dominant dimensions:** [top 2-3 dimensions and why]

### Content Spec
- **Platform:** [Instagram Reels / TikTok / Carousel / Stories / YouTube Shorts / etc.]
- **Format:** [Talking head / B-roll montage / Screen recording / Carousel slides / etc.]
- **Duration:** [Xs] or [N slides]
- **Hook (exact text):** "[Write the actual hook — first 3 seconds / first slide]"
- **Hook type:** [Contrarian / Mistake / Numbered / Time-based / Question / Problem-to-Payoff / Counterintuitive]
- **Content arc:** [Myth-busting / Transformation / Tutorial / Day-in-the-life / Challenge / BTS / Hot-take / Education]
- **CTA:** [Follow / Save / Comment [prompt] / DM [word] / Link in bio / Share]
- **Engagement trigger:** [Question in caption / "Save this for later" / "Tag someone who..." / Poll sticker / etc.]

### Brand Alignment
- **Voice applied:** [How the brand's voice_tone shapes this specific piece]
- **StoryBrand connection:** [Which SB7 element: hero problem / villain / guide authority / plan / transformation]
- **Offer connection:** [If applicable — which offer's promise, pain_point, or objection this serves]
- **Pain/Desire addressed:** [Specific marketing_pain_point or marketing_desire from Brand/Offer data]

### Production Notes
- **Difficulty:** [Easy / Medium] (Hard = violates Phone Camera Rule, simplify)
- **Equipment:** Phone camera + [tools: Canva / CapCut / natural light / ring light / tripod]
- **Estimated production time:** [15 min / 30 min] (max 30 min for Easy, 45 min for Medium)
- **Visual direction:** [Describe the look: lighting, framing, text overlay style, color mood]
- **Audio:** [Trending sound / voiceover / original audio / music from library]
- **Text overlays:** [Key text that appears on screen — captions, bullet points, stats]

### Saturation Check
- **Format saturation in client niche:** [Innovation / Early Adoption / Growth / Peak — from lifecycle]
- **Opportunity window:** [Estimated time before this reaches saturation in client niche]
- **Key differentiator vs competitors:** [What makes THIS version unique — brand voice, angle, combination]

### Posting Recommendation
- **Suggested day/time:** [Based on platform best practices + audience habits]
- **Caption draft:** [2-3 lines of caption text aligned with voice_tone]
- **Hashtags:** [5-10 relevant hashtags, mix of broad + niche]
- **Cross-posting potential:** [Which other platforms can this be adapted for with minimal effort]
```

**Pillar format:** [YouTube video / Blog post / Live / Podcast episode]
**Pillar duration:** [X minutes]
**Total micro-pieces:** [N]

| # | Micro-Piece | Platform | Extract From | Hook Adaptation | Post Day |
|---|---|---|---|---|---|
| 1 | [Clip: key moment] | Reels | Timestamp [X:XX-X:XX] | "[Adapted hook]" | Day 1 |
| 2 | [Quote card] | Stories | Quote at [X:XX] | Visual with key quote | Day 2 |
| 3 | [Carousel: steps] | Instagram | Steps section | "[Adapted carousel hook]" | Day 3 |
| 4 | [Thread] | Twitter/X | Main argument | "[Thread hook]" | Day 4 |

## 4. Final Checklist

Before delivering any brief, verify ALL items:

- [ ] Hook tested: first 3 words carry tension, not filler
- [ ] STEPPS score >= 10/18
- [ ] Voice verified: sounds like the brand, not generic
- [ ] StoryBrand element present: connects to hero problem, guide, or transformation
- [ ] Phone Camera Rule: producible with smartphone + Canva + 30 min
- [ ] Saturation checked: format is at Innovation or Early Adoption in client's niche
- [ ] Engagement trigger included: the content asks for a specific audience action
- [ ] CTA matches funnel stage: awareness = follow/save, consideration = comment/DM, conversion = link/buy
- [ ] Cross-posting noted: brief mentions which other platforms can reuse this
- [ ] Pain/Desire documented: brief maps to a specific brand or offer data point
