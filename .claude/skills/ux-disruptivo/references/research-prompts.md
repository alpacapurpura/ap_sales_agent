## How to Use

1. Identify which domain(s) match the feature
2. Pick 3-5 queries (mix specific + general)
3. Run via `WebSearch`
4. `WebFetch` top 2-3 relevant results
5. Extract: layout patterns, component usage, interaction models, visual hierarchy
6. Synthesize into 3+ principles for the user
