## Layout Paradigm Variety

Each proposal MUST use a different layout paradigm. Choose 3 from:

| Paradigm | Description | Best for |
|---|---|---|
| **Card Grid** | Equal-weight cards in responsive grid | Overviews, dashboards, galleries |
| **Sidebar + Main** | Navigation/filters left, content right | Detail views, config, mail-like |
| **Wizard / Stepper** | Sequential steps with progress | Setup flows, multi-step forms |
| **Split View** | Two equal panels side by side | Comparison, code/preview, before/after |
| **Dashboard** | Mixed widgets: charts + tables + KPIs | Analytics, monitoring |
| **Timeline** | Chronological vertical flow | Activity feeds, logs, history |
| **Kanban** | Columns with draggable cards | Pipeline, status management |
| **Master-Detail** | List left, detail right (or expandable) | CRM, email, records |
| **Full-Width Table** | Data table dominates the view | Admin panels, bulk operations |
| **Hero + Grid** | Prominent top section + grid below | Landing, marketing, featured items |

## Presentation Order

1. Present all 3 proposals + Option D in a single message
2. After each proposal, add a blank line separator
3. End with: *"¿Cuál te llama más la atención? También puedes mezclar elementos de varias."*
