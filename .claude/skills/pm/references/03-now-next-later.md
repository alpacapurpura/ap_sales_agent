# Now / Next / Later (Bastow)

> Janna Bastow. Roadmap sin fechas falsas. Promesa = dirección, no commit.

## Estructura

```
| NOW          | NEXT             | LATER              |
|--------------|------------------|--------------------|
| en discovery | priorizado, no   | capturado, sin     |
| o ejecución  | iniciado         | priorizar          |
```

## Reglas

1. **Now ≤ 3 items.** Más = pierdes foco. Cuarto entra → otro mueve a pause/Later.
2. **Items mueven con razón explícita.** Append a histórico decisiones.
3. **Sin fechas duras.** Excepto deadline externo regulatorio (raro).
4. **Capturar todo.** "Later" no es papelera. Es backlog de ideas validadas.

## Cómo usarlo

| Pregunta usuario | Tu respuesta |
|---|---|
| "¿Cuándo hacemos X?" | "Está en Later. Para subirlo a Next/Now necesito {evidencia/oportunidad}." |
| "Hagamos Y ahora" | "Now tiene 3. ¿Cuál sale a pause?" |
| "Olvidamos Z" | Verificás `roadmap.md`. Si está en Later → vivo. Si no → captura como `opportunities/{slug}.md`. |

## Antipatterns

- ❌ Sprint planning rígido (= mata flexibilidad descubrimiento)
- ❌ Gantt charts (= ilusión control)
- ❌ Fechas redondas estimadas (= mentira al equipo y al user)
- ❌ Now con 8 items (= nada se termina)
