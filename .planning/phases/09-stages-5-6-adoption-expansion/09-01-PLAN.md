- Method `get_customer_health_by_offer(tenant_id, start_date, end_date)`: Query `CustomerProfileModel` joined with `SaleModel` (stage=SaleStage.CONVERSION, status=SaleStatus.COMPLETED). Filter customers with `lifecycle_stage IN (LifecycleStage.CUSTOMER, LifecycleStage.EVANGELIST, LifecycleStage.CHURNED)`. Group by `SaleModel.offer_id`. For each offer, count `DISTINCT CustomerProfileModel.id` total, active (is_inactive==False), inactive (is_inactive==True). Use `func.count(distinct(...)).filter(...)` pattern. Always include `tenant_id == tenant_id` on both tables.

- Method `get_avg_ttv_by_offer(tenant_id, start_date, end_date) -> Dict[str, float]`: Subquery for first post-purchase event per customer: `select(JourneyEventModel.profile_id, func.min(JourneyEventModel.occurred_at))` where `tenant_id == tenant_id`, grouped by profile_id. Main query joins SaleModel + CustomerProfileModel + subquery. Filter: `first_conversion_at IS NOT NULL` and `first_event_at > first_conversion_at`. Calculate `func.avg(func.extract("epoch", first_event_at - first_conversion_at) / 86400)` grouped by offer_id. Return dict mapping offer_id string to avg TTV days (rounded to 1 decimal). Exclude NULL averages.

- Method `get_total_customers_and_sales(tenant_id, start_date, end_date) -> tuple[int, int]`: Return (total_customers_with_lifecycle_stage_in_CUSTOMER_EVANGELIST_CHURNED, total_sales_count_CONVERSION_COMPLETED). Used for MiniFunnel: Ventas -> Activos.

- Method `get_refunds(tenant_id, start_date, end_date) -> tuple[int, float, str]`: Query `SaleModel` where `status == SaleStatus.REFUNDED` and `tenant_id == tenant_id`. Return (count, sum_amount, currency). Source-agnostic per CONTEXT.md -- no filtering by source column.

All queries use SQLAlchemy 2.0 `select()` syntax. Import models from CRM module: `CustomerProfileModel`, `JourneyEventModel` from `crm.infrastructure.models.customer_model`, `SaleModel` from `crm.infrastructure.models.sale_model`. Import enums from `crm.domain.enums`.
