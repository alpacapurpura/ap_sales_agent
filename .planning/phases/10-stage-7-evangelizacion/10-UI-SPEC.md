## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (gap-1), inline padding (px-1, py-0.5) |
| sm | 8px | Compact element spacing (space-y-2, gap-2) |
| md | 16px | Default element spacing (p-4, gap-4) |
| lg | 24px | Section padding (gap-6, px-6) |
| xl | 32px | Layout gaps (py-8) |
| 2xl | 48px | Major section breaks (py-12) |
| 3xl | 64px | Page-level spacing |

Exceptions: `px-3` (12px) for horizontal padding — carried from Phases 4-9 panel rhythm. 12px is a multiple of 4, no grid violation.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` — `0 0% 100%` light / `222.2 47.4% 11.2%` dark | Panel background, surfaces |

## Panel Layout Contract

### Structure (top to bottom)

Follows established detail panel rhythm from Phases 5-9.

**Primary focal point:** K-Factor KPI (position 1, primary row) — largest numeric value on the panel, first element the business owner scans.

```
1. Timestamp                    — text-xs text-muted-foreground px-3 pb-1
2. Primary Header KPIs (3)      — flex items-center gap-6 px-3 py-2
3. Secondary Header KPIs (2)    — flex items-center gap-6 px-3
4. MiniFunnel                   — Clientes Activos (N) -> Evangelistas (M) = X%
5. Bottleneck Banners           — space-y-2 px-3 (conditional)
6. Group 1: Referidos           — Evangelist cards + summary metrics
7. Candidatos a Evangelista     — NPS >= 9 customers awaiting promotion
8. Group 2: Reputacion          — NPS summary + UGC/testimonial count
```

### Header KPIs (3+2 Pattern from Phase 9)

**Primary row (3 KPIs):**

| Position | Label | Tooltip Hint | Format |
|----------|-------|-------------|--------|
| 1 | K-FACTOR | "Por cada cliente, cuantos nuevos clientes genera a traves de referidos. Mayor a 1.0 significa crecimiento viral" | `X.XX` (2 decimals) |
| 2 | REFERIDOS CONVERTIDOS | "Cantidad de ventas que vinieron de un codigo de referido o enlace compartido" | integer, `toLocaleString('es-ES')` |
| 3 | NPS SCORE | "Calificacion de satisfaccion de tus clientes del 0 al 10. Arriba de 8 es excelente" | `X.X` (1 decimal, 0-10 scale) |

**Secondary row (2 KPIs):**

| Position | Label | Tooltip Hint | Format |
|----------|-------|-------------|--------|
| 1 | REVENUE REFERIDO | "Dinero total generado por ventas atribuidas a referidos" | Dual currency (es-MX primary + USD secondary) |
| 2 | EVANGELISTAS ACTIVOS | "Clientes que tienen un codigo de referido activo y han generado al menos una conversion" | integer |

### MiniFunnel

| Source Label | Source Value | Target Label | Target Value |
|-------------|-------------|-------------|-------------|
| "Clientes Activos" | total active customers (from CRM) | "Evangelistas" | active evangelist count |

Conversion rate: `(evangelistas / clientes_activos * 100).toFixed(1)%`

### Group 1: Referidos

**Group header:** Section title "Referidos" with subtitle showing total referral revenue.

**Evangelist cards** (adapted from OfferHealthCard pattern):

```
+-------------------------------------------------------+
| [Avatar/Initial]  Nombre del Evangelista               |
|                   Codigo: REF-XXXX     [Activo badge]  |
|                                                        |
| Referidos enviados: 12  |  Convertidos: 3  |  $X,XXX  |
+-------------------------------------------------------+
```

Card specifications:
- Container: `rounded-lg border p-3 space-y-1` (matches OfferHealthCard)
- Name: `text-sm font-semibold`
- Referral code: `text-xs text-muted-foreground font-mono`
- Status badge: emerald for active, muted for inactive
- Metrics row: `flex items-center gap-4 text-xs`
- Revenue: dual currency format (carried from Phase 8-9)

**When no evangelists exist:** Show empty state (see Copywriting Contract).

### Candidatos a Evangelista Section

Visible only when there are NPS >= 9 respondents not yet promoted to EVANGELIST.

```
+-------------------------------------------------------+
| Candidatos a Evangelista                    (N total)  |
|                                                        |
| [Avatar] Cliente A  NPS: 10  [Promover]               |
| [Avatar] Cliente B  NPS: 9   [Promover]               |
+-------------------------------------------------------+
```

- Container: `rounded-lg border border-dashed border-purple-300 dark:border-purple-700 p-3`
- Each candidate row: `flex items-center justify-between py-1`
- NPS score: emerald badge
- "Promover" button: `Button variant="outline" size="sm"` with purple text

### Group 2: Reputacion

**NPS Summary Card:**

```
+-------------------------------------------------------+
| NPS Score: X.X                                        |
|                                                        |
| [===== Promotores (N) =====][== Pasivos ==][Detract]  |
|  9-10: N (XX%)    7-8: N (XX%)    0-6: N (XX%)       |
|                                                        |
| Encuestas enviadas: N  |  Tasa de respuesta: XX%      |
+-------------------------------------------------------+
```

- Proportional bar: CSS widths (same technique as HealthBar from Phase 9)
  - Promoters (9-10): `bg-emerald-500`
  - Passives (7-8): `bg-yellow-500`
  - Detractors (0-6): `bg-red-500`
  - Min 1% visual width for non-zero segments (same rule as HealthBar)
- Response rate: `text-xs text-muted-foreground`

**UGC Count:**

- Simple metric line: "Testimonios recopilados: N" with `text-sm`
- Below: "Escritos: N | Audio: N" with `text-xs text-muted-foreground`

### Bottleneck Definitions

| Type | Metric Label | Threshold | Severity Logic | Tip |
|------|-------------|-----------|---------------|-----|
| `low_k_factor` | "K-Factor bajo" | < 0.5 critical, < 1.0 warning | Based on K-Factor value | "Incentiva a tus mejores clientes a compartir su codigo de referido. Ofrece descuentos o beneficios exclusivos." |
| `low_nps_response` | "Pocas respuestas NPS" | < 20% response rate | Based on surveys sent vs responses | "Envia mas encuestas de satisfaccion. Los clientes que responden tienden a ser tus mejores promotores." |

## Interaction Contract

### Promote to Evangelist Flow

1. User clicks "Promover" on a candidate row OR directly promotes from CRM
2. Confirmation dialog appears (shadcn Dialog):
   - Title: "Promover a Evangelista"
   - Body: confirmation copy from Copywriting Contract
   - Actions: "Cancelar" (outline) | "Confirmar" (default)
3. On confirm: POST to backend, optimistic UI update, toast notification via sonner
4. Card moves from Candidatos section to Referidos group

### Survey Trigger Flow

1. User clicks "Enviar Encuesta NPS" button in Reputacion group header
2. Dialog opens with:
   - Select: "Para que oferta?" (dropdown of active offers) OR "Cliente especifico" (search)
   - Delivery method: "Link universal" (default) | "WhatsApp conversacional"
   - Preview of survey link
3. On confirm: POST to backend, toast: "Encuesta enviada correctamente"

### Data Refresh

- React Query with 5-min staleTime (matches all other panels)
- Hook pattern: `useEvangelizationDetail()` following `useAdoptionDetail` / `useExpansionDetail`
- Auth: `useAuth()` + `fetchClient` pattern from Clerk

### Empty State (no evangelists, no NPS)
```
flex flex-col items-center justify-center py-12 px-4 text-center:
  h3 text-sm font-semibold: "Sin evangelistas aun"
  p text-xs text-muted-foreground mt-2 max-w-md: [empty state body]
  span text-xs text-primary underline mt-3: "Ir a Clientes"
```

### Partial Data States
- **Evangelists exist but no NPS data:** Show Referidos group normally, Reputacion group shows "Sin datos de satisfaccion" empty card
- **NPS data exists but no evangelists:** Show Candidatos section prominently, Referidos shows "Aun no has promovido evangelistas"
- **No referral conversions yet:** Evangelist cards show 0 conversions with muted styling
