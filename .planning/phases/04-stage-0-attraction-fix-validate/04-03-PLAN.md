<task type="auto">
  <name>Task 1: Build validation comparison script</name>
  <files>backend/scripts/validate_attraction.py</files>
  <action>
    Create `backend/scripts/validate_attraction.py` — an on-demand script that validates ETL data against live provider APIs.

    **Script structure:**
    1. Accept optional CLI args: `--tenant-id` (default: Visionarias tenant UUID from env or config), `--tolerance` (default: 0.05 = 5%)

    2. **Discover connected providers**: Use ChannelRegistry.get_available_channels(tenant_id, "attraction") to determine which providers are connected. Skip disconnected providers.

    3. **For each connected provider**:
       a. Get credentials via ConnectionPortImpl.get_credentials(tenant_id, provider_name)
       b. Call provider.extract_metrics(tenant_id, credentials, start_date=30 days ago, end_date=today) to get **live API values**
       c. Read OfficialMetricsRepository.get_channel_summary(tenant_id, "attraction", "last_30_days") to get **ETL-stored values**
       d. Compare per (channel_slug, metric_name): if abs(live - stored) / max(live, 1) > tolerance -> FAIL, else PASS
       e. Handle edge cases: both values are 0 -> PASS, stored exists but live call fails -> SKIP with warning

    4. **Output structured report**:
       ```
       === Attraction Metrics Validation Report ===
       Tenant: Visionarias ({tenant_id})
       Date range: 2026-02-13 to 2026-03-15
       Tolerance: 5%

       Provider: meta
         ig-organic / reach:       PASS  (ETL: 12,500 | Live: 12,800 | Diff: 2.3%)
         ig-organic / engagement:  PASS  (ETL: 3,200  | Live: 3,150  | Diff: 1.6%)
         meta-ads / reach:         PASS  (ETL: 45,000 | Live: 44,200 | Diff: 1.8%)
         meta-ads / spend:         FAIL  (ETL: 120.50 | Live: 135.20 | Diff: 10.9%)

       Provider: google_analytics
         google-organic / sessions: PASS (ETL: 8,300 | Live: 8,450 | Diff: 1.8%)
         ...

       Provider: tiktok
         SKIPPED — not connected

       === Summary ===
       Passed: 18/22 metrics
       Failed: 2/22 metrics
       Skipped: 2/22 metrics (disconnected providers)
       ```

    5. Exit code: 0 if all connected metrics pass, 1 if any fail

    6. **Run command**: `docker exec -t visionarias_brain_dev python scripts/validate_attraction.py`
       - Must be runnable inside Docker container
       - Uses async entrypoint (asyncio.run)
       - Imports project modules (sys.path setup if needed)

    7. **Error handling**: If a provider API call fails during validation, mark that provider as SKIP with the error message. Don't crash the whole script.
