| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), inline padding |
| sm | 8px | Channel row vertical padding (`py-2`), compact spacing (`space-y-2`) |
| md | 16px | Default element spacing (`space-y-4`, `p-4`), section padding (`px-3 py-3`) |
| lg | 24px | Header KPI horizontal gaps (`gap-6`) |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: none -- follows identical spacing pattern established in CaptureDetail (Phase 5)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 500 (medium) | 1.43 (default) | Channel names, metric values |
| Label | 10px (`text-[10px]`) | 400 (regular) | 1.5 | KPI labels (uppercase tracking-wide), secondary lines, muted annotations |
| Small | 12px (`text-xs`) | 400 (regular) | 1.5 | Source labels, group summaries, timestamps, conversion rate text |
| KPI Value | 20px (`text-xl`) | 600 (semibold) | 1.2 | Header KPI numbers, MiniFunnel numbers |

Font feature: `tabular-nums` on all numeric displays for column alignment.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` | Panel background, detail container |
| Secondary (30%) | `hsl(var(--muted))` with `/30` opacity | MiniFunnel background (`bg-muted/30`), hover states (`hover:bg-muted/50`) |
| Accent (10%) | `hsl(var(--primary))` | Conversion rate percentage in MiniFunnel, active CTA text |
| Destructive | `hsl(var(--destructive))` | Not used in this phase (no destructive actions) |
| Muted foreground | `hsl(var(--muted-foreground))` | KPI labels, source labels, timestamps, secondary lines |
| Stale warning | `yellow-500/50` border, `yellow-600` text (light) / `yellow-400` text (dark) | Stale data badge ("Desactualizado") and last-updated timestamp |

Accent reserved for: MiniFunnel conversion rate percentage display, primary action text in CostLink

## Layout Contract

### NurtureDetail Panel Structure

```
[Ultima actualizacion: 16 mar 2026, 14:32]          -- text-xs muted, px-3 pb-1

[TOTAL MQLs]   [CONVERSION]   [COSTO POR MQL]       -- 3 KPIs, flex gap-6 px-3 py-2
 2,100           24.7%          $12.50                -- text-xl semibold tabular-nums

[Leads (8,500) --> MQLs (2,100) = 24.7%]             -- MiniFunnel, bg-muted/30 rounded-lg

[v] Retargeting Omnichannel                           -- ChannelGroup, defaultOpen
    Alcance: 45.2k | Clicks: 3.1k | Gasto: $1,250
    |-  Meta Retargeting    Alcance  Clicks  Gasto   -- ChannelRow with 3 metrics
    |   "3 campanas activas"                          -- secondary line text-[10px]
    |   [v] Campaign drill-down (collapsable)         -- CampaignDrillDown
    |       Campaign A      12.5k    820    $450
    |       Campaign B       8.3k    540    $380
    |-  Google Retargeting  Alcance  Clicks  Gasto
    |   "2 campanas activas"
    |-  TikTok Retargeting  Alcance  Clicks  Gasto
    |   "1 campana activa"

[v] Automatizacion                                    -- ChannelGroup, defaultOpen
    Emails: 12.5k | Open Rate: 42.3% | Click Rate: 8.1%
    |-  Mailerlite           Enviados  Open%  Click%  -- ChannelRow with 3 metrics
    |   "Ultima: Newsletter Semana 12"                -- secondary line
    |   [v] Campaign drill-down (collapsable)
    |       Newsletter Semana 12   2,500  45.2%  9.8%
    |       Promo Curso Nuevo      1,800  38.1%  7.2%
    |-  AI SDR               Follow-ups  Respuestas  -- ChannelRow with 2 metrics
    |   "X respuestas (Y%)"                           -- secondary line
    |   OR [Proximamente] badge if no data

[>] Canales Disponibles                               -- ChannelGroup, defaultOpen=false
    N canales por configurar
```

### CampaignDrillDown Interaction

- **Trigger**: Click anywhere on the ChannelRow (entire row is clickable when channel has campaigns)
- **Indicator**: Chevron icon (ChevronDown from lucide-react) at far right of ChannelRow, rotates 180deg when expanded
- **Animation**: shadcn Collapsible component with default height transition
- **Content**: List of individual campaigns, each as a compact sub-row with campaign name (left) and metrics (right)
- **Sub-row style**: `pl-10` indent (aligns with channel name after icon), `py-1.5`, `text-xs` for all text, `bg-muted/20` background
- **Separator**: No dividers between campaigns -- spacing only (`space-y-0.5`)

### "Proximamente" Badge (AI SDR fallback)

- Used when AI SDR follow-up feature is not yet implemented
- shadcn `Badge` with `variant="secondary"`
- Copy: "Proximamente"
- Replaces metric display area in ChannelRow
- Channel name and icon still visible

## Interaction States

| State | Visual Treatment |
|-------|-----------------|
| Loading | 4 Skeleton elements: h-6 w-48, h-32 w-full, h-6 w-48, h-32 w-full (identical to CaptureDetail) |
| Error | Muted text in `p-4 text-sm text-muted-foreground` container |
| Empty (no channels connected) | Empty state heading + body copy centered in panel |
| Channel connected, has data | Full ChannelRow with metrics |
| Channel connected, zero data | "0 MQLs" + "Sin actividad en los ultimos 30 dias" |
| Channel connected, stale | Yellow "Desactualizado" badge + last-updated date + refresh button |
| Channel not connected | Name + "Configurar" badge only |
| AI SDR not implemented | Name + icon + "Proximamente" secondary badge |
| Campaign drill-down collapsed | Chevron pointing right, row clickable |
| Campaign drill-down expanded | Chevron rotated 180deg, sub-rows visible with indent |
| Hover on ChannelRow | `bg-muted/50` transition |
| Hover on campaign sub-row | `bg-muted/30` transition |
