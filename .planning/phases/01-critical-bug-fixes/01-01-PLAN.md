<objective>
Fix the two Meta-related critical bugs: update the deprecated v19.0 API version to v24.0 (BUGFIX-01), and replace the singleton `FacebookAdsApi.init()` pattern with per-instance API objects to prevent multi-tenant data leaks (BUGFIX-02). Pin the `facebook-business` package version.

Purpose: Meta API calls have been returning HTTP 400 since Sept 2025 because v19.0 is expired. The singleton SDK pattern is a security vulnerability that can leak tenant data in concurrent async requests.
Output: Updated MetaAdapter, pinned dependency, passing unit tests for version + tenant isolation.
