## New Component Specifications

### OpportunityDetail

**Structure (top to bottom):**
1. Timestamp line: `text-xs text-muted-foreground px-3 pb-1` -- "Ultima actualizacion: {date}"
2. Header KPIs row: 3 columns -- Total SQLs, Conversion (MQL->SQL), Costo por SQL
3. MiniFunnel: MQLs ({n}) -> SQLs ({n}) = {x}%
4. Bottleneck banners (0-2): one per threshold violation
5. ChannelGroup "Checkout" (defaultOpen)
6. ChannelGroup "Links de Pago" (defaultOpen)
7. ChannelGroup "Calificacion" (defaultOpen)
8. ChannelGroup "Canales Disponibles" (defaultOpen=false)

**Loading state:** 4 Skeleton blocks matching NurtureDetail pattern:
```
<Skeleton className="h-6 w-48" />
<Skeleton className="h-32 w-full" />
<Skeleton className="h-6 w-48" />
<Skeleton className="h-32 w-full" />
```

**Error state:** Single `<div className="p-4 text-sm text-muted-foreground">` with error copy.

### BottleneckBanner

**Props:**
```typescript
interface BottleneckBannerProps {
  type: 'abandoned_cart' | 'meeting_no_show';
  metricLabel: string;
  currentRate: number;       // 0-100
  severity: 'warning' | 'critical';
  threshold: number;         // threshold that was crossed
  tip: string;
}
```

**Layout:**
```
[AlertTriangle icon] {metricLabel}: {currentRate}% (> {threshold}%)
{tip text}
```

**Sizing:**
- Container: `rounded-lg border p-3` (12px padding)
- Icon: `h-4 w-4` (16px)
- Metric line: `text-sm font-medium` (14px/500)
- Tip line: `text-xs text-muted-foreground mt-1` (12px, 4px top margin)

**Behavior:**
- Static display, not dismissible (per user decision -- action triggers deferred)
- Multiple banners stack vertically with `space-y-2` (8px gap)
- No animation on initial render
- Icon: `AlertTriangle` from lucide-react

## Channel-Specific Visual Contracts

### Checkout Group

**Group summary line format:**
```
Checkouts: {n} | Abandonos: {n} | Valor: ${total} | Tasa Abandono: {x}%
```

#### checkout-init (Checkout Iniciado)
- Icon: shopping cart emoji or `ShoppingCart` lucide icon mapped to string
- CHANNEL_ICONS entry: `'checkout-init': '\uD83D\uDED2'` (shopping cart)
- Metrics displayed: count + value (currency)
- Secondary line: `de {X} MQLs = {Y}%` (conversion from Stage 2)
- Source label: "Shopify"

#### abandoned-cart (Carrito Abandonado)
- Icon: `'abandoned-cart': '\u26A0\uFE0F'` (warning sign)
- Metrics displayed: count + abandoned value (currency)
- Secondary line: `{X}% del checkout` (abandonment ratio relative to checkout-init)
- Inline bottleneck badge: shown when abandonment rate exceeds 30%
  - 31-50%: yellow outline badge "Alerta"
  - >50%: red outline badge "Critico"
- Source label: "Shopify"

### Payment Links Group

**Group summary line format:**
```
Links: {n} | Valor: ${total}
```

#### link-enviado (Link de Pago Enviado)
- Icon: `'link-enviado': '\uD83D\uDD17'` (link)
- Metrics displayed: count + total link value (currency)
- Secondary line: `de {X} MQLs = {Y}%`
- Source label: "Sales Agent"
- Note: If sales_agent does not yet emit payment link events, show "Proximamente" badge (same pattern as ai-sdr in NurtureDetail)

#### checkout-lp (Checkout Landing Page)
- Icon: `'checkout-lp': '\uD83D\uDCBB'` (laptop)
- Always shows "Proximamente" badge (landing page generation not yet built)
- Source label: "Landing Page"

### Qualification Group

**Group summary line format:**
```
Reuniones: {booked} | Completadas: {completed} | No-show: {no_show} | Asistencia: {attendance_rate}%
```

#### meeting-booked (Reuniones Agendadas)
- Icon: `'meeting-booked': '\uD83D\uDCC5'` (calendar)
- Primary metric: `{n} reuniones` (total booked count)
- Secondary lines (stacked, each `text-[10px] text-muted-foreground`):
  - `{n} completadas ({x}%)` -- star metric, shown first
  - `{n} no-show ({x}%)` -- with inline bottleneck badge if threshold exceeded
  - `{n} reprogramadas`
- Conversion line: `de {X} MQLs = {Y}%`
- Inline bottleneck badge on no-show line:
  - 21-40%: yellow outline badge "Alerta"
  - >40%: red outline badge "Critico"
- Source label: "Scheduling"

## Interaction States

### Panel-Level States

| State | Visual Treatment |
|-------|-----------------|
| Loading | 4 Skeleton blocks (h-6 w-48, h-32 w-full pattern) |
| Error | Muted text with error copy, no retry button |
| Empty (no data) | Muted text with empty state copy |
| Populated | Full panel with header KPIs + MiniFunnel + groups + optional bottleneck banners |

### Channel-Level States (inherited from ChannelRow)

| State | Visual Treatment |
|-------|-----------------|
| Connected with data | Icon + name + source label + metric values |
| Connected with zero | Icon + name + "0 {metric}" + "Sin actividad en los ultimos 30 dias" |
| Connected no data | Icon + name + "---" + "Sin datos" |
| Disconnected | Icon + name + "Configurar" badge |
| Proximamente | Icon + name + "Proximamente" badge (secondary variant) |
| Stale | Yellow "Desactualizado" badge + timestamp + refresh button |

### Bottleneck States

| State | Banner | Inline Badge |
|-------|--------|-------------|
| Normal (below threshold) | Not rendered | Not rendered |
| Warning (yellow threshold) | Yellow banner at panel top | Yellow outline badge on channel row |
| Critical (red threshold) | Red banner at panel top | Red outline badge on channel row |
| Both bottlenecks active | Two banners stacked (`space-y-2`) | Each row has its own badge |

## New GroupType Summary Cases

```typescript
// Add to ChannelGroup.tsx buildSummary switch
case 'checkout': {
  const abandonRate = totals.abandonment_rate;
  const abandonStr = abandonRate != null ? ` | Tasa Abandono: ${abandonRate.toFixed(1)}%` : '';
  return `Checkouts: ${formatNumber(totals.count ?? 0)} | Abandonos: ${formatNumber(totals.abandoned ?? 0)} | Valor: ${formatCurrency(totals.value ?? 0)}${abandonStr}`;
}
case 'payment_links': {
  return `Links: ${formatNumber(totals.count ?? 0)} | Valor: ${formatCurrency(totals.value ?? 0)}`;
}
case 'qualification': {
  const attended = totals.attendance_rate;
  const attendStr = attended != null ? ` | Asistencia: ${attended.toFixed(1)}%` : '';
  return `Reuniones: ${formatNumber(totals.booked ?? 0)} | Completadas: ${formatNumber(totals.completed ?? 0)} | No-show: ${formatNumber(totals.no_show ?? 0)}${attendStr}`;
}
```
