   ```
   Then install the theme and a11y addons:

   ```
   Then install all deps:
   ```
   docker exec -it visionarias_client_dev npm install
   ```

   IMPORTANT: The init command will generate example stories in `src/stories/`. Delete ALL generated example files (Button.stories.ts, Header.stories.ts, Page.stories.ts, Button.tsx, Header.tsx, Page.tsx, etc.) immediately after init. We create our own.

3. **Overwrite `.storybook/main.ts`** (the init will generate one, but we need to customize it):
   ```typescript
   import type { StorybookConfig } from '@storybook/nextjs-vite';

   const config: StorybookConfig = {
     stories: ['../src/**/*.stories.@(js|jsx|ts|tsx)'],
     addons: [
       '@storybook/addon-essentials',
       '@storybook/addon-themes',
       '@storybook/addon-a11y',
     ],
     framework: '@storybook/nextjs-vite',
     staticDirs: ['../public'],
   };

   export default config;
   ```
   Do NOT include `@storybook/addon-onboarding` or `@storybook/addon-interactions` (unneeded bloat).

4. **Overwrite `.storybook/preview.ts`:**
   ```typescript
   import type { Preview } from '@storybook/react';
   import { withThemeByClassName } from '@storybook/addon-themes';
   import '../src/app/globals.css';

   const preview: Preview = {
     parameters: {
       controls: {
         matchers: {
           color: /(background|color)$/i,
           date: /Date$/i,
         },
       },
     },
     decorators: [
       withThemeByClassName({
         themes: {
           light: '',
           dark: 'dark',
         },
         defaultTheme: 'light',
       }),
     ],
   };

   export default preview;
   ```
   Key points:
   - Import `globals.css` to load Tailwind v4 + all CSS custom properties
   - `withThemeByClassName` adds/removes `dark` class on the preview container
   - Empty string for light = no class = `:root` styles apply
   - `'dark'` for dark mode = `html.dark` styles apply

5. **Update `package.json` scripts** -- add two scripts:
   - `"storybook": "storybook dev -p 6006 --host 0.0.0.0"` (--host 0.0.0.0 required for Docker access from host)
   - `"build-storybook": "storybook build"`

6. **Verify Storybook starts** by running:
   ```
   docker exec -it visionarias_client_dev npx storybook dev -p 6006 --host 0.0.0.0 --ci
   ```
   The `--ci` flag exits after successful build. Check output for "Storybook started" message.

**Story pattern for EVERY component** -- follow this exact structure:
```typescript
import type { Meta, StoryObj } from '@storybook/react';
import { ComponentName } from '@/components/ui/component-name';

const meta = {
  title: 'Category/ComponentName',  // Atoms/, Molecules/, Organisms/, Tokens/
  component: ComponentName,
  tags: ['autodocs'],
  argTypes: { /* variant/size controls */ },
} satisfies Meta<typeof ComponentName>;

export default meta;
type Story = StoryObj<typeof meta>;

export const Default: Story = { args: { children: 'Label', variant: 'default' } };
export const VariantName: Story = { args: { variant: 'name' } };
```
