  <files>backend/src/core/database.py</files>
  <action>
    Modify the `create_engine` call in `backend/src/core/database.py` to add connection pool health checking:

    ```python
    engine = create_engine(
        settings.DATABASE_URL,
        pool_pre_ping=True,
        pool_recycle=300,
    )
    ```

    - `pool_pre_ping=True`: Issues a lightweight SELECT 1 before handing out a connection from the pool. If the connection is dead, it transparently reconnects. This is the standard fix for "server closed the connection unexpectedly".
    - `pool_recycle=300`: Recycles connections every 5 minutes, preventing them from going stale due to PostgreSQL's idle timeout or firewall rules.

    Do NOT change SessionLocal, get_db, or any other code in this file. Only modify the engine creation line.
  </action>

  </verify>
